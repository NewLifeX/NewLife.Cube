# 魔方 WebAPI 核心接口架构（前端皮肤对接标准）

> 版本：2026-04-16  
> 适用范围：NewLife.Cube 第三代（WebAPI 主线）

---

## 1. 文档目标

本文档用于统一各前端皮肤（Vue/React/Arco/Naive/TDesign 等）对接 NewLife.Cube 的 API 规范，重点定义：

1. 最小可运行接入所需接口（必要接口）。
2. 可选增强能力接口（高级接口）。
3. 认证、CRUD、OAuth 的统一语义与参数约定。

---

## 2. 必要接口与高级接口

### 2.1 必要接口（最小可运行集合）

> 前端可硬编码站点名称和登录入口，因此 `/Auth/LoginConfig` 不属于必要接口。

| 模块 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 认证 | POST | `/Auth/Login` | 密码登录（`category` 为空表示密码登录） |
| 认证 | POST | `/Auth/Refresh` | 刷新令牌 |
| 认证 | GET | `/Auth/Info` | 当前用户信息 |
| 认证 | POST | `/Auth/Logout` | 登出 |
| 菜单 | GET | `/Cube/MenuTree` | 当前用户可访问菜单树 |
| 实体 | GET | `/{type}` | 列表查询（分页/筛选/排序；可选 `viewFilter` 视图筛选 JSON，OSC-260819e483） |
| 实体 | GET | `/{type}/Detail?id=123` | 详情 |
| 实体 | POST | `/{type}` | 新增 |
| 实体 | PUT | `/{type}` | 编辑 |
| 实体 | PATCH | `/{type}` | 单条改字段 `{ id, values }`（WebAPI；白名单=EditForm∩非只读∩非主键，OSC-260819e483） |
| 实体 | POST | `/{type}/BatchUpdateFields` | 批量改字段 `{ keys, field, value }`（WebAPI；≤500 条，OSC-260819e483） |
| 实体 | DELETE | `/{type}?id=123` | 单条删除 |

### 2.2 高级接口（按需实现）

| 模块 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 登录配置 | GET | `/Auth/LoginConfig` | 登录方式、OAuth 提供商、站点名称/版权/Logo 等开关配置 |
| 安全增强 | GET | `/Auth/Challenge` | Challenge-Response 公钥与 challengeId |
| 验证码 | POST | `/Auth/SendCode` | 发送手机/邮箱验证码 |
| 验证码登录 | POST | `/Auth/Login` | 统一登录，需传 `category: "mobile"` 或 `"mail"` |
| 忘记密码 | POST | `/Auth/ResetPassword` | 验证码重置密码 |
| 注册 | POST | `/Auth/Register` | 统一注册 |
| OAuth 注册辅助 | GET | `/Auth/OAuthPendingInfo` | OAuth 回跳预填信息 |
| 微信登录（小程序） | POST | `/Sso/WxMiniLogin` | `{ code, appId? }`，appId 也可走 `X-App-Id` 头 |
| 微信登录（App） | POST | `/Sso/WxAppLogin` | 同上 |
| 元数据 | GET | `/{type}/GetPage` | 页面字段元数据；setting 含 `masterTimeName`/`masterTimeDisplayName`（主时间字段信息，无 MasterTime 为 null，OSC-0016）；字段含 `required`（非空必填，`nullable===false` 且非只读且非主键，OSC-260819e483）；匿名不下发权限表达式 |
| 导出 | GET | `/{type}/ExportFile` | 数据导出 |
| 导入 | POST | `/{type}/ImportFile` | 数据导入 |
| 上传 | POST | `/{type}/UploadFile` | 附件上传 |
| 图表 | GET | `/{type}/GetChartData` | 图表数据；可选携带与列表一致的搜索条件（数组遵循 GetList 约定），缺省保持原行为 |
| 批量删除 | DELETE | `/{type}?id=1&id=2&id=3` | 重复参数形式 |
| MFA 二步验证 | * | `/Mfa/*` | 详见 [认证接口设计.md](./认证接口设计.md)（AUTH-10）；非本文件最小集 |
| 用户呈现配置 | GET/PUT | `/Cube/UserProfile` | 当前用户布局/主题/工作台 JSON；PUT upsert |
| 实体视图配置 | GET/PUT/DELETE | `/Cube/ViewProfile` | 按 `typePath`；DELETE 恢复默认视图；body 含 `filtersJson`（命名视图筛选记忆）、`queriesJson`（预定义查询 JSON，实体级个人配置，OSC-0016）、`pageSize`（typePath 级页面条数，0=未配置）与 `formJson`（add/edit/detail 受限表单布局） |
| 实体视图模板 | GET/PUT/POST/DELETE | `/Cube/ViewProfileTemplate` | 仅系统管理员；`UserId=0` 全局模板（每 typePath 一份），body 含 `viewsJson`/`filtersJson`（视图/筛选模板域）；有效配置按 个人 > 模板 > 系统默认 解析；表单域为全局唯一（OSC-0013），不属模板域 |
| 实体评论 | GET/POST/DELETE | `/Cube/EntityComment` | GET: `category`+`linkId`（可选 `parentId`）；POST 可带 `parentId` 同表回复、可选 `mentionUserIds` 提及用户（最多 20，成功后写站内信，通知失败不回滚评论，OSC-260819e483）；DELETE 本人或管理员 |
| 实体自动化 | GET/POST/PUT/DELETE | `/Cube/Automation` | 列表（`typePath` 必填，不返回 HookToken）；详情含 GraphJson/HookToken（可配置者）；POST 创建、PUT 更新；更新另有 `PUT/POST /Cube/Automation/Update`（避免 IIS 禁 PUT 时误打到创建）；DELETE `?id=`。**实体自动化为 C# GraphJson 执行器，不是 FlowGram 运行时**（OSC-260815fa86） |
| 自动化运行 | GET | `/Cube/Automation/Runs` | `typePath`；可选 `automationId`/`recordKey`/分页。数据来自系统审计 `Log`（Action=`Automation`） |
| 自动化手动跑 | POST | `/Cube/Automation/Run` | `{ automationId, recordKey }` |
| 自动化元数据 | GET | `/Cube/Automation/Meta` | `typePath` 字段名/显示名/类型 |
| 自动化实体列表 | GET | `/Cube/Automation/Entities` | `permission=update\|insert`；有对应权限的实体，供 create/find 下拉 |
| 自动化接收人 | GET | `/Cube/Automation/Recipients` | `kind=user\|role\|department`；可选 `key`；最多 50 条 |
| 站内信 | GET | `/Cube/Automation/Inbox` | 当前用户 InApp；`pageIndex`/`pageSize`/`unread` |
| 站内信未读数 | GET | `/Cube/Automation/Inbox/UnreadCount` | `{ count }` |
| 站内信已读 | POST | `/Cube/Automation/Inbox/Read` | `{ id?, all? }` |
| 自动化 Webhook | POST | `/Cube/Automation/Hook/{token}` | 匿名；无效 token 404；`X-Cube-Signature` HMAC；60 次/分钟 |
| AI 配置 | GET | `/Cube/GetAiConfig` | `{ AISwitch, AIPrimaryColor, AISecondaryColor }`；登录即可（无 `/api` 前缀） |
| AI 对话 | POST | `/Ai/AiChat` | SSE `data: {type}`；body `sessionId/message/page/mode/id/query/area/controller/think`；路径须绝对 |
| AI 工具回传 | POST | `/Ai/OperationResult` | `{ checkpointId, result }`，`result` 字符串 ≤8192 |
| 批量启用 | GET | `/{type}/EnableSelect` | `keys`；一次建议 ≤200（皮肤门禁） |
| 批量禁用 | GET | `/{type}/DisableSelect` | 同上 |

```text
Step 1  POST /Auth/Login

Step 6  accessToken 过期时调用 POST /Auth/Refresh
```

## 4. 认证接口规范（AuthController）

### 4.1 登录（必要）

```http
POST /Auth/Login
Content-Type: application/json
```

请求示例：

```json
{
  "username": "admin",
  "password": "admin",
  "category": "",
  "challengeId": ""
}
```

字段说明：

| 字段 | 必填 | 说明 |
|------|------|------|
| `username` | 是 | 用户名 |
| `password` | 是 | 密码明文，或加密密文 |
| `category` | 否 | 字符串枚举：`""`（密码）、`mobile`、`mail`、`oauth` |
| `challengeId` | 否 | 走 Challenge-Response 时传入 |

### 4.2 验证码登录（高级）

验证码登录与密码登录共用 `/Auth/Login` 接口，区别在于 `category` 字段取值不同：

```http
POST /Auth/Login
Content-Type: application/json
```

请求示例（手机验证码）：

```json
{
  "username": "13800138000",
  "password": "123456",
  "category": "mobile"
}
```

说明：
- `category` 在验证码登录场景仅允许 `mobile` 或 `mail`。
- `password` 字段承载验证码。

### 4.3 Challenge（高级）

```http
GET /Auth/Challenge
```

响应示例：

```json
{
  "code": 0,
  "data": {
    "challengeId": "a3f2c8e1-4b7d-11ef-9012-0800200c9a66",
    "publicKey": "-----BEGIN PUBLIC KEY-----\n...\n-----END PUBLIC KEY-----"
  }
}
```

> 本文档不提供前端加密代码示例。

### 4.4 发送验证码（高级）

```http
POST /Auth/SendCode
Content-Type: application/json
```

请求示例：

```json
{
  "channel": "Sms",
  "username": "13800138000",
  "action": "Login"
}
```

### 4.5 忘记密码（高级）

```http
POST /Auth/ResetPassword
Content-Type: application/json
```

请求示例：

```json
{
  "username": "13800138000",
  "code": "123456",
  "newPassword": "NewPass@2026",
  "confirmPassword": "NewPass@2026"
}
```

### 4.6 统一注册（高级）

```http
POST /Auth/Register
Content-Type: application/json
```

`category` 使用字符串枚举：

- `""`：用户名密码注册（默认）
- `mobile`：手机验证码注册
- `mail`：邮箱验证码注册
- `oauth`：OAuth 回跳后绑定注册

#### 注册示例 1：用户名密码

```json
{
  "category": "",
  "username": "newuser",
  "email": "newuser@example.com",
  "password": "Strong@2026",
  "confirmPassword": "Strong@2026"
}
```

#### 注册示例 2：手机验证码

```json
{
  "category": "mobile",
  "mobile": "13800138001",
  "username": "13800138001",
  "code": "123456",
  "password": "Strong@2026",
  "confirmPassword": "Strong@2026"
}
```

#### 注册示例 3：邮箱验证码

```json
{
  "category": "mail",
  "email": "newuser@example.com",
  "username": "newuser@example.com",
  "code": "123456",
  "password": "Strong@2026",
  "confirmPassword": "Strong@2026"
}
```

#### 注册示例 4：OAuth 绑定注册

```json
{
  "category": "oauth",
  "oauthToken": "6d58fdf6...",
  "username": "newuser",
  "password": "Strong@2026",
  "confirmPassword": "Strong@2026"
}
```

#### 多租户请求头契约

开启多租户（`CubeSetting.EnableTenant=true`）后，以下请求头用于定位/校验租户（注册、微信登录及所有受保护接口）：

| Header | 语义 | 说明 |
|--------|------|------|
| `X-Tenant` | **租户编码（Code）** | 优先按 `Tenant.FindByCode` 解析；`X-Tenant-Id` 已废弃，仅兼容老客户端（数字ID） |
| `X-App-Id` | OAuth 应用 AppId | 注册时按 `OAuthConfig.FindByAppId` 定位其所属租户（优先于 X-Tenant）；微信登录在请求体未传 appId 时兜底 |

- 多租户开启时，注册必须携带 `X-App-Id` 或 `X-Tenant`，否则拒绝注册。
- 伪造、不存在或已禁用的租户会被拒绝（400/403）。
- 未开启多租户时不校验租户，与旧逻辑一致。

## 5. OAuth 流程（登录与注册分离）

### 5.1 OAuth 已绑定用户：直接登录

```text
Step 1  前端跳转 /Sso/Login/{provider}?r=/admin/index
Step 2  后端重定向到 OAuth 提供商，用户完成授权
Step 3  回跳后端，识别到已绑定用户
Step 4  直接颁发 accessToken/refreshToken
```

### 5.2 OAuth 首次用户：进入注册

```text
Step 1  前端跳转 /Sso/Login/{provider}?r=/auth/register
Step 2  后端重定向到 OAuth 提供商，用户完成授权
Step 3  回跳后端，识别到未绑定用户，返回 oauthToken
Step 4  前端调用 GET /Auth/OAuthPendingInfo?token=xxx 获取预填信息
Step 5  前端提交 POST /Auth/Register（category=oauthbind）
Step 6  注册成功后颁发 accessToken/refreshToken
```

## 6. 实体 CRUD 规范

### 6.1 列表（必要）

```http
GET /{type}?pageIndex=1&pageSize=20&sort=Id&desc=true&Q=关键字&dtStart=...&dtEnd=...&viewFilter={json}
```

- 排序单列：`sort=字段` + `desc=true`（OSC-260819e483 维持单列）。
- `viewFilter`（可选）：视图筛选 JSON（`{ logic, conditions[] }`，≤4KB），后端可下推时并入查询（数据权限表达式仍生效），无法下推则忽略服务端过滤。
- 字段级校验头：写请求（POST/PUT/PATCH）携带 `X-Cube-Field-Validation: 1` 时按 GetPage `required` 校验缺失必填（OSC-260819e483）；不带该头与历史行为一致。

### 6.2 详情（必要）

```http
GET /{type}/Detail?id=123
```

### 6.3 新增（必要）

```http
POST /{type}
```

### 6.4 编辑（必要）

```http
PUT /{type}
```

### 6.5 单条改字段（OSC-260819e483，仅 WebAPI）

```http
PATCH /{type}
Content-Type: application/json

{ "id": "123", "values": { "Name": "新名称" } }
```

白名单 = EditForm ∩ 非只读 ∩ 非主键；未知字段 400；部分失败返回 `{ ok, fail, errors[] }`。

### 6.6 批量改字段（OSC-260819e483，仅 WebAPI）

```http
POST /{type}/BatchUpdateFields
Content-Type: application/json

{ "keys": ["1", "2"], "fields": [ { "field": "Enable", "value": true }, { "field": "Name", "value": "新名称" } ] }
```

`keys` 空或 >500 返回 400；多字段 ≤50 个（兼容单字段 `{ field, value }`）；逐行应用全部字段 Find+Valid+ChangeType+OnUpdate，部分失败返回 `{ ok, fail, errors[] }`。

### 6.7 删除（必要）

```http
DELETE /{type}?id=123
```

### 6.6 批量删除（高级）

```http
DELETE /{type}?id=1&id=2&id=3
```

> 采用重复参数形式，不使用逗号拼接形式。条件删除必须包含至少一个筛选条件。
