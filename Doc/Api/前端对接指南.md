### ArcoVue：UserProfile 消费约定（OSC-0004）

皮肤包 `NewLife.Cube.ArcoVue` 通过下列接口同步壳偏好（布局 / 主题 / 工作台）：

```
GET  /Cube/UserProfile
PUT  /Cube/UserProfile
```

- 响应/请求体为线缆模型：`layoutJson` / `themeJson` / `workspaceJson`（**JSON 字符串**列），前端 parse 为逻辑对象后再驱动 `RootLayout` 与主题注入。
- 策略：localStorage 先行 → 登录后 GET 覆盖本地 → 变更防抖 300–500ms PUT；失败保留脏标记并提示。
- 外观设置页：`/settings/appearance`（静态路由，不占用菜单权限位）。
- **硬约束：** CRUD（`core/`、`views/crud/`）禁止读取 `userProfile` store；记录抽屉保持右侧弹出。

### ArcoVue：ViewProfile 与命名视图（OSC-0005 / OSC-0006）

```
GET    /Cube/ViewProfile?typePath=
PUT    /Cube/ViewProfile
DELETE /Cube/ViewProfile?typePath=
```

- 线缆字段：`view`、`columnsJson`、`viewsJson`、`activeViewId`（及 gantt/card/filtersJson 预留）、`dashboardJson`（OSC-2608280e9e 页面仪表盘，实体级，不跟命名视图走）。
- **页面仪表盘 Widget（OSC-2608280e9e）**：`cubeApi.widget.sources|catalog|query|data`；配置 `PUT /Cube/ViewProfile` 带 `dashboardJson`。空串清除个人域（下次 GET 继承模板）；显式 `{"version":1,"widgets":[]}` 表示用户清空。ArcoVue 在 `main.ts` 调用 `registerPlatformWidgets()`；业务包可 `registerWidget` 再注册 kind。洞察槽 `WidgetHost` 只经 inject，不读 `useListQuery`。
- **Unique(UserId, TypePath)** 一行内存多命名视图；`viewsJson` 为权威，`columnsJson` 与活跃视图同步。
- **ViewKind**（OSC-0006）：`table | tree | card | kanban | calendar | gantt`。类型映射写在 `NamedView.mapping`（`viewsJson` 内）；前端**不读写** `ganttJson`/`cardJson`。卡片映射（OSC-0007）：`layout`（`standard | large | row`，缺失/非法回落 `standard`）、`bodyColumns`（`1|2|3`，标准/偏大时 `3` 回落 `2`）、`fieldOrientation`（`horizontal|vertical`，缺省 `vertical`）。
- 创建门禁：无 Parent/`children` 等树元数据时禁止创建 `tree`；看板需分组+标题候选；日历需 DateTime；甘特需 ≥2 个 DateTime。
- **pageSize：** table/tree/card 用常规分页；kanban/calendar/gantt 进入时 GetList 使用较大 pageSize（默认 200，上限 500）。
- 看板只读分列（本号不拖拽写回）；日历配置：开始必选、结束可选、标题、颜色。
- 列表主舞台：表格/树为 VisActor VTable；卡片/看板/日历/甘特为 `features/views/*`；排序参数 `sort` + `desc`。
- 打开详情：表格行**双击**或操作列「详情」；卡片/看板左下按钮（有权则详情+编辑+删除）→ 右侧抽屉。

### ArcoVue：EntityComment 评论与表单提交（OSC-0008）

```
GET    /Cube/EntityComment?category=&linkId=&parentId=
POST   /Cube/EntityComment               # body 含 parentId 表示回复
DELETE /Cube/EntityComment?id=
```

- 字段：`category`（typePath 去前导 /）、`linkId`（记录主键）、`parentId`（0=顶层）、`rootId`、`replyUser`、`content`、`createUser/createUserId/createTime`。
- RecordDrawer 评论 Tab：顶层 + 一层回复缩进；发表/回复/删除本人（后端仍校验）；api-core 暴露 `cubeApi.comment.*`。
- 历史 Tab：`GET /Admin/Log` 分页（20/页）+ `action` 筛选 + 展示增强（OSC-0008）。
- **表单提交归一化**：新增/编辑提交时按字段元数据把枚举/Lov 字符串值转回 `number`（对齐 MVC 版 System.Text.Json 绑定，避免「请求数据格式不正确」）；可空 String 字段空值提交 `""`。

### 字段元数据驱动

```javascript
// 获取页面元数据（包含 setting + list/addForm/editForm/detail/search）
async function getPageMeta(entity) {
    const result = await fetch(`/api/${entity}/getpage`, {
        headers: {
            'Authorization': `Bearer ${localStorage.getItem('accessToken')}`
        }
    });
    return await result.json();
}

// 根据元数据渲染表单
function renderForm(fields, formData) {
    return fields.map(field => {
        const value = formData[field.name];
        
        switch (field.type) {
            case 'String':
                if (field.dataSource) {
                    return renderSelect(field, value);
                }
                if (field.length > 200) {
                    return renderTextarea(field, value);
                }
                return renderInput(field, value);
            
            case 'Int32':
            case 'Int64':
                if (field.dataSource) {
                    return renderSelect(field, value);
                }
                return renderNumber(field, value);
            
            case 'Boolean':
                return renderSwitch(field, value);
            
            case 'DateTime':
                return renderDatePicker(field, value);
            
            default:
                return renderInput(field, value);
        }
    });
}
```

### CRUD 调用示例

```javascript
// API 封装
class CubeApi {
    constructor(baseUrl, entity) {
        this.baseUrl = baseUrl;
        this.entity = entity;
    }
    
    get headers() {
        return {
            'Content-Type': 'application/json',
            'Authorization': `Bearer ${localStorage.getItem('accessToken')}`
        };
    }
    
    // 列表查询
    async list(params = {}) {
        const query = new URLSearchParams(params).toString();
        const result = await fetch(`${this.baseUrl}/api/${this.entity}?${query}`, {
            headers: this.headers
        });
        return result.json();
    }
    
    // 详情
    async detail(id) {
        const result = await fetch(`${this.baseUrl}/api/${this.entity}/${id}`, {
            headers: this.headers
        });
        return result.json();
    }
    
    // 添加
    async add(data) {
        const result = await fetch(`${this.baseUrl}/api/${this.entity}`, {
            method: 'POST',
            headers: this.headers,
            body: JSON.stringify(data)
        });
        return result.json();
    }
    
    // 更新
    async update(id, data) {
        const result = await fetch(`${this.baseUrl}/api/${this.entity}/${id}`, {
            method: 'PUT',
            headers: this.headers,
            body: JSON.stringify({ id, ...data })
        });
        return result.json();
    }
    
    // 删除
    async delete(id) {
        const result = await fetch(`${this.baseUrl}/api/${this.entity}/${id}`, {
            method: 'DELETE',
            headers: this.headers
        });
        return result.json();
    }
    
    // 获取页面元数据（一次返回列表/表单/搜索字段）
    async getPage() {
        const result = await fetch(
            `${this.baseUrl}/api/${this.entity}/getpage`,
            { headers: this.headers }
        );
        return result.json();
    }
}

// 使用示例
const studentApi = new CubeApi('http://localhost:5000', 'student');

// 获取列表
const listResult = await studentApi.list({ pageIndex: 1, pageSize: 20 });
console.log(listResult.data);

// 添加
const addResult = await studentApi.add({ name: '张三', classId: 1 });
console.log(addResult);

// 更新
const updateResult = await studentApi.update(1, { name: '张三修改' });
console.log(updateResult);
```

### 令牌刷新

```javascript
// 请求拦截器，自动刷新令牌
async function fetchWithAuth(url, options = {}) {
    const token = localStorage.getItem('accessToken');
    
    const response = await fetch(url, {
        ...options,
        headers: {
            ...options.headers,
            'Authorization': `Bearer ${token}`
        }
    });
    
    // 401 时尝试刷新令牌
    if (response.status === 401) {
        const refreshToken = localStorage.getItem('refreshToken');
        const refreshResult = await fetch('/api/user/refresh', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ refreshToken })
        });
        
        const { code, data } = await refreshResult.json();
        if (code === 0) {
            localStorage.setItem('accessToken', data.accessToken);
            localStorage.setItem('refreshToken', data.refreshToken);
            
            // 重试原请求
            return fetch(url, {
                ...options,
                headers: {
                    ...options.headers,
                    'Authorization': `Bearer ${data.accessToken}`
                }
            });
        } else {
            // 刷新失败，跳转登录
            window.location.href = '/login';
        }
    }
    
    return response;
}
```

### 多租户请求头传递

开启多租户后，前端需在所有请求中携带租户标识，后端按 `X-Tenant`（租户编码）定位并校验租户：

```javascript
// 请求拦截器统一注入租户头
async function fetchWithTenant(url, options = {}) {
    const tenantCode = localStorage.getItem('tenantCode'); // 登录响应头 X-Tenant 或用户信息
    return fetch(url, {
        ...options,
        headers: {
            ...options.headers,
            'Authorization': `Bearer ${localStorage.getItem('accessToken')}`,
            'X-Tenant': tenantCode   // 租户编码（Code），非数字ID
        }
    });
}
```

- `X-Tenant` 传**租户编码**（如 `abc`），`X-Tenant-Id` 已废弃仅兼容（数字ID）。
- 微信登录：请求体 `appId` 或请求头 `X-App-Id`（二选一，同时存在且不一致会被拒绝）；登录成功后在**响应头 `X-Tenant`** 返回租户编码，前端保存后供后续请求使用。
- 注册：可传 `appId`（转 `X-App-Id` 头）或 `tenantCode`（转 `X-Tenant` 头）；多租户开启时两者必须至少传一个，否则注册被拒。
- 使用 api-core 的皮肤可配置 `request.additionalRequestHeaders` 全局注入 `X-Tenant`，无需逐个请求处理。

## 38.5 最佳实践

### 统一错误处理

```javascript
// 响应拦截器
async function handleResponse(response) {
    const result = await response.json();
    
    if (result.code !== 0) {
        switch (result.code) {
            case 401:
                // 未登录
                window.location.href = '/login';
                break;
            case 403:
                // 无权限
                alert('无权限访问');
                break;
            default:
                // 其他错误
                alert(result.message || '操作失败');
        }
        throw new Error(result.message);
    }
    
    return result;
}
```

### 分页组件封装

```vue
<!-- Vue 分页组件示例 -->
<template>
  <div class="pagination">
    <el-pagination
      v-model:current-page="currentPage"
      v-model:page-size="pageSize"
      :total="total"
      :page-sizes="[10, 20, 50, 100]"
      layout="total, sizes, prev, pager, next, jumper"
      @size-change="handleSizeChange"
      @current-change="handleCurrentChange"
    />
  </div>
</template>

<script setup>
import { ref, watch } from 'vue';

const props = defineProps({
  page: Object
});

const emit = defineEmits(['change']);

const currentPage = ref(props.page?.pageIndex || 1);
const pageSize = ref(props.page?.pageSize || 20);
const total = ref(props.page?.totalCount || 0);

watch(() => props.page, (newPage) => {
  if (newPage) {
    currentPage.value = newPage.pageIndex;
    pageSize.value = newPage.pageSize;
    total.value = newPage.totalCount;
  }
});

function handleSizeChange(size) {
  emit('change', { pageIndex: 1, pageSize: size });
}

function handleCurrentChange(page) {
  emit('change', { pageIndex: page, pageSize: pageSize.value });
}
</script>
```
