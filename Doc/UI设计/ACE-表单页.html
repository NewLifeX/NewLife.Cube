一、按钮语义修正（本次设计稿核心变更）

现状问题：「清空密码」使用绿色主操作样式（btn-success），与「保存」同色同级，语义完全相反——清空密码是高危动作，绿色传递了「安全、推荐」的错误暗示；「取消」使用红色（btn-danger），视觉过重，红色应保留给真正的破坏性操作（如删除）。

修改前 语义冲突

清空密码 清空密码 绿色实底 —— 与「保存」竞争，暗示推荐操作
取消 取消 红色实底 —— 视觉过重，误导为危险操作

修改后 语义清晰

清空密码 清空密码 描边警示 —— 保留提示性但不抢主操作
取消 取消 中性描边 —— 与 ACE 通用表单模板一致

布局上「清空密码」靠左、「保存 / 取消」靠右——三级视觉权重：主操作（实底绿）＞ 警示（描边橙）＞ 次要（描边灰）。 修改文件：Areas/Admin/Views/User/_Form_Action.cshtml（用户表单）； ACE 通用模板 Views/ACE/_Form_Action.cshtml 的取消按钮已是中性色。

二、表单控件规范

  • 两列栅格：大屏 2 列（col-sm-6），小屏 1 列；标签右对齐、输入控件高度统一 30px。
  • 聚焦态：主色边框 + 2px 主色柔光圈（box-shadow: 0 0 0 2px rgba(43,125,188,.15)）。
  • 帮助文本：字段说明统一 12px 灰字，位于控件下方 4px 间距。
  • 输入组：图标 addon 浅灰蓝底 #f5f8fc，与输入框圆角拼接。
  • 底部按钮区：浅灰底 #fafbfc + 顶部分隔线，按钮高度 32px、主按钮最小宽度 84px。
