## 1. 审计说明

- **审计依据**：《皮肤设计规范》v2.0 各章节的【必须】/【推荐】/【按配置】要求
- **审计维度**：
  - 登录：基础（密码登录/注册/第三方）、高级（验证码/找回/图片验证码）、安全（加密传输-按配置）
  - 布局：布局形态、用户信息区、移动端兼容、首页=工作台
  - 工作台：卡片类型、卡片三能力（拖动/保存/隐藏）、权限过滤
  - 菜单与路由：权限过滤、图标、多级选中/面包屑、URL 路由、多标签
  - 列表页：查询区、表格区、单元格渲染、列宽、图表视图、分页、高级菜单、操作列
  - 表单页：新增/编辑/详情、字段类型、分组布局、交互
  - 通用体验：状态反馈、危险确认、按钮权限
- **审计方式**：源码检查 + 运行时验证（优先本地自托管站点），每项需注明证据
- **更新节奏**：皮肤每完成一轮补齐后回填，先主皮肤后其余
