### 3.1 ACE 皮肤（MVC 参考：NewLife.CubeNC + Views/ACE）

> ACE 是 MVC 版默认主题，核心视图在 `NewLife.CubeNC/Views/Shared/*`（列表/表单/工具栏），ACE 专属视图在 `Views/ACE/*`（布局/菜单/操作列/分页）。

| 维度 | 结论 | 证据 |
|------|------|------|
| 登录 | ✅ 完整 | MVC 版登录页能力矩阵（`Doc/AUTH-用户认证.md` API 列全可用），含密码/验证码/找回/图片验证码/第三方登录/加密传输 |
| 布局 | ✅ 左右 | `_Layout` + `_Left`（左菜单）+ `_Layout_Nav`（面包屑），多级菜单展开/收起 |
| 用户信息区 | ✅ | 顶栏用户下拉（个人信息/修改密码/退出登录） |
| 移动端 | 🟡 | 引入 `bootstrap-responsive`，但基于 Bootstrap 3 老式主题，手机/平板完整适配需专项验证 |
| 工作台 | ✅ 完整 | `Dashboard.cshtml` + `Widgets/`：WidgetManager 扫描注册、13 部件（系统 7 + 个人 2 + 内容 4）、5 种卡片类型（Kpi/Content/Html/Kv/Chart）、jquery-ui 拖拽排序、`SaveOrder` 持久化（Parameter）、`WidgetController` 启停（隐藏）、角色/AdminOnly 权限过滤 |
| 菜单 | ✅ | `_Left`：权限过滤（ViewBag.Menus）+ 租户过滤 + FontAwesome 图标 + 默认图标兜底 + 多级菜单 + 首个菜单默认展开 + 当前高亮 |
| 路由 | ✅ | 服务端渲染，URL 天然跟随，分享直达 |
| 多标签 | 🟡 | MVC 版无多标签能力，待评估是否需要 |
| 列表页 | ✅ | `Shared/List.cshtml`（NavView/工具栏/Charts 上图表/表格/分页/Charts2 下图表）；`_List_Data_Item` 单元格类型渲染（日期/时间/数字/百分比/枚举/外键/IP/大文本/链接/彩色文字/彩色行底色）；`_List_Data_Stat` 统计行；`_List_Data_Action` 操作列（查看/编辑/删除/软删除恢复） |

| 高级菜单 | ✅ | `_List_Toolbar_Adv`：导出 Excel/Csv/Xml/Json/Zip、导入、分享、删除选中/全部、备份/还原/备份导出/清空、代码生成 |
| 表单页 | ✅ | `_Form_Body`（分组 Tabs）/`_Form_Group`（响应式栅格 + html/markdown/大文本全宽）/`_Form_Editor`（类型分发）/`_Form_Item`（下拉/多选/Map/树/用户部门/文件/HTML/Markdown/模糊搜索） |
