一、问题分析：表格分界线过淡

结论：线深线浅是「偏好」，但现状叠加了两个客观瑕疵。

  • 偏好维度：极简轻线（Ant Design 派）与清晰网格各有拥趸，无唯一正确答案——因此做成配置项而非单方面改深。
  • 瑕疵 ①：多机制弱化共存。现状同时使用 4 种分隔机制——行线 #f0f2f5、竖线 #f0f2f5、斑马纹 #fbfcfd、悬停 #f7fafd——全部处于「似有似无」状态，无主无次。设计上应「一主一辅」。
  • 瑕疵 ②：对比度低于可辨阈值。行线 #f0f2f5 对白底对比度约 1.06:1，1080p 屏幕上基本不可辨，横向串行（读错行）风险客观存在。

解决思路：三档配置（轻量 / 标准 / 网格），每档内部机制主次分明、对比度达标；默认「标准」档解决「看不清」问题，偏好极简或偏好强网格的用户各选所需。

三、落地映射

  • 配置项：CubeSetting.TableStyle（Light/Standard/Grid，默认 Standard）+ CubeSetting.TableDensity（Compact/Normal，默认 Compact），在「魔方设置 → 界面配置」页以下拉框配置。
  • 样式注入：Views/ACE/_Layout.cshtml 的 <body> 输出 cube-table-{style} cube-density-{density}，ace-ui.css 按 class 切换变量。
  • 生效范围：ACE 主题下所有 .table-data-list 表格（列表页 / 树形表 / 服务器信息表），当前仅 ACE 皮肤消费。
