### IMP-1 Vue 前端多语言未落地（界面文案仍为中文）

- **是什么问题**：Vue 前端 11 语资源与 `vue-i18n` 已安装，但 309 个源文件里没有一处 `$t`/`t` 调用，导航栏也没有语言切换入口；切换 `localStorage['cube-language']` 只会改变 `<html lang>` 与 `Accept-Language`，界面仍是中文。
- **有什么危害**：对外宣称的"Vue 11 语"不成立，海外用户无法使用；与 `Doc/多语言本地化.md` 的能力描述不一致。
- **怎么修改**：先在导航栏挂载 `core/components/LanguageSwitch.vue`，再按页面分批把文案改为 `t()`（可复用 React 侧"中文原文为键"的做法）。
- **修改后的遗憾**：需要分批投入，期间中文原文即键，改动面较大。
- 严重程度：建议
- 触发路径：任意浏览器语言非中文 → 登录 Vue 版 → 界面仍为中文。

### IMP-2 React 业务页面文案未全量接入 11 语

- **是什么问题**：React 已具备 11 语切换；登录/注册页、工作台、列表引擎（搜索栏/表格/列设置/权限弹窗/工具条/分页）已完成，个人中心、安全中心、表单弹窗与 AI 助手仍为硬编码中文。
- **有什么危害**：切换语言后框架按钮与登录/工作台/列表会变，但个人中心等页面文字不变，体验割裂。
- **怎么修改**：按 `src/i18n/app/*.ts`（中文原文为键）继续分批把剩余业务页文案改为 `t()`。
- **修改后的遗憾**：需逐页迁移与翻译，短期存在中英混排。
- 严重程度：建议
- 触发路径：切换语言为 English → 打开个人中心/安全中心/AI 助手。

### IMP-3 共享服务端日志模板仍为中文

- **是什么问题**：`NewLife.CubeNC` 共享源码中约 84 条 `XTrace/WriteLog` 日志模板是中文，与文档"日志统一英文模板"不一致。
- **有什么危害**：日志无法统一切换语言，且与文档约定漂移。
- **怎么修改**：按 `L.TLog("English template")` 迁移；`check-english-messages.ps1` 已支持共享文件，迁移后移除该脚本中针对共享文件日志的白名单。
- **修改后的遗憾**：存量日志检索口径会变化，需要一次性对齐。
- 严重程度：可选
- 触发路径：服务端输出日志/审计。
