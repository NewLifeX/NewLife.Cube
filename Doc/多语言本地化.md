# 魔方多语言本地化

> 基线：NewLife.Core 12 编译期词表｜运行时 11 种语言｜英文为源文与兜底

## 1. 能力范围

| 面 | 状态 | 说明 |
|---|---|---|
| 后端 API 消息 | ✅ 已接入 | `Locales/*.yml` + `L.T`，覆盖 CRUD、认证、权限、校验等公共消息 |
| 请求语言识别 | ✅ 已接入 | `?lang=` → Cookie → `Accept-Language` |
| Vue 前端 | ✅ 已接入 | `vue-i18n`，11 语切换并持久化 |
| MVC 视图 / 实体元数据 | ⏳ 后续批次 | 视图数量大（551 个 cshtml、约 2.3 万汉字），逐主题迁移 |

## 3. 工作方式

1. `NewLife.Core` 包内的源生成器读取 `Locales/*.yml`，编译期生成压缩语言表与自动注册代码。
2. `NewLife.Cube` 与 `NewLife.CubeNC` 共用 `NewLife.Cube/Locales`（NC 通过 `AdditionalFiles` 挂载），词表只有一份事实源。
3. 请求进入 `UseCube` 后由 `UseCubeLocalization()` 写入 `CurrentUICulture`；`Localization.Culture` 保持 `null`，避免进程级覆盖。
4. 消息以英文为源文：`L.T("Operation succeeded")` / `L.T("{0} succeeded!", action)`；缺少译文自动回退英文。
5. `XException` 构造器内部已调用 `Localization.Translate`，直接写英文即可。

## 4. 新增一条消息

```csharp
// 源文（英文，占位符与译文必须一致）
throw new XException("The requested data [{0}] does not exist.", id);

// BCL 异常需要显式翻译
throw new InvalidOperationException(L.T("Only available in development mode."));
```

同步在全部 10 份 `Locales/*.yml` 中补键，然后运行：

```powershell
pwsh -File check-locales.ps1 -LocaleDir NewLife.Cube/Locales -Baseline zh-Hans.yml -SourceDir NewLife.Cube
```

CI 的 `localization` job 会校验键集合、占位符与格式说明符一致。

## 5. 语言选择

| 来源 | 示例 | 优先级 |
|------|------|--------|
| 查询参数 | `?lang=zh-TW` | 最高 |
| Cookie | `.AspNet.Culture=zh-CN` | 次之 |
| 请求头 | `Accept-Language: ja-JP` | 再次 |
| 宿主配置 | `CubeSetting.Language` | 默认值 |

`CubeSetting.Language` 为空时跟随浏览器/系统；设置后作为未匹配请求的默认语言。

## 6. Vue 前端

- 语言文件：`NewLife.Cube.Vue/web/core/i18n/locales/*.ts`
- 切换：`setLanguage()` 写入 `localStorage['cube-language']`，同步 `<html lang>` 与 Element Plus locale。
- 请求：axios 统一携带 `Accept-Language`，后端按同一条链路返回本地化消息。

## 7. 边界

- MVC 视图与实体 `DisplayName`/`Description` 仍以中文为主，属于后续批次；API 与 Vue 已完整覆盖公共消息。
- 翻译质量以中文版为准；英文为源文，其他语言缺失时自动回退英文。
- 新增语言只需追加 `Locales/{code}.yml` 并在 `readme-languages.json` 登记；不要修改已有键。
