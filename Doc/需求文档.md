# 魔方（NewLife.Cube）需求文档

> 版本：v6.12 | 日期：2026-07-15

本文档描述魔方（NewLife.Cube）快速开发平台的愿景、核心目标和功能方向。完成状态在[功能清单](功能清单.md)中追踪，详细设计在[架构设计](架构设计.md)中展开。

---

## 1. 背景与愿景

### 1.1 系统定位

魔方是面向**系统管理后台的快速开发基础设施层**，让开发团队把时间花在业务差异化上，而不是重复搭建后台管理基础功能。

- **通用后台能力**：认证、权限、菜单、CRUD、导入导出、日志、配置开箱即用
- **多前端支持**：一套后端 API 同时服务 Vue / React / Angular / Svelte / Blazor / MVC Razor 等多种前端
- **可扩展架构**：通过 EntityController 继承、字段元数据、IModule 插件机制深度定制
- **超大数据支撑**：基于 XCode ORM 的分表、读写分离、二级缓存，支撑单表 100 亿级数据

### 1.2 愿景

魔方成为 .NET 生态中最流行的后台快速开发平台——"定义实体即得管理界面"，开发者只需关注业务模型定义，框架自动完成认证授权、界面渲染、数据导出、日志审计等基础设施。第三代 WebAPI 主线 + 多前端皮肤生态，让同一套后端无痛对接任意前端框架。

## 3. 功能需求

### 3.1 M1 基础服务与扩展

- **M1-1 统一响应协议**：所有 API 统一返回 `ApiResponse<T>` 结构，`code=0` 表示成功，列表接口使用 `ApiListResponse<T>` 携带分页信息。
- **M1-2 权限注解**：`[EntityAuthorize(PermissionFlags.Detail)]` 控制 Action 权限，`[Menu(100, true, Icon = "fa-table")]` 自动注册菜单。
- **M1-3 模块化插件**：通过 `IModule` 接口实现功能模块自动注册，NuGet 包引用后自动注册服务和路由。
- **M1-4 跨域支持（CORS）**：内置 CORS 支持，支持全允许和指定来源两种模式，支持 credentials 传递。
- **M1-5 数据保护（DPAPI）**：基于 DPAPI 的数据保护，密钥持久化到数据库。
- **M1-6 数据保留策略**：定时清理过期数据，支持按保留天数自动清理，支持按数据表配置不同策略。
- **M1-7 应用插件管理**：应用扩展插件的注册与查看管理。
- **M1-8 备份还原服务**：数据库定时备份与还原，备份文件可管理。

### 3.2 M2 用户认证与安全

- **M2-1 密码策略**：可配置的正则表达式密码强度规则，默认 8 位以上含数字/大小写字母/特殊字符。
- **M2-2 密码登录**：支持用户名/邮箱/手机号 + 密码登录，登录失败达阈值后临时封禁（用户级 + IP 级），支持 MFA 二次验证拦截。
- **M2-3 JWT Token 认证**：登录成功返回 `accessToken` + `refreshToken`，支持令牌刷新和滑动过期阈值配置。
- **M2-4 Challenge-Response 加密传输**：RSA-OAEP/SHA-256 加密密码传输，`challengeId` 限时一次性使用防重放，`AllowPlainPassword=false` 时拒绝明文。
- **M2-5 图形验证码**：SVG 格式图形验证码，防止自动化攻击，有时效性。
- **M2-6 验证码登录**：支持手机验证码或邮箱验证码登录，通过 `category=mobile/mail` 区分。
- **M2-7 验证码记录**：短信/邮件验证码的发送记录查询与过期管理。
- **M2-8 用户注册**：支持用户名密码注册、手机/邮箱验证码注册、OAuth 回跳注册，注册后可自动登录。
- **M2-9 登录风控**：基于 IP 子网（三段 /24、两段 /16）的登录失败封禁策略，阈值和时间可配置。
- **M2-10 OAuth 第三方登录**：对接微信/钉钉/GitHub/QQ/支付宝/微软/百度/淘宝/微博/企业微信等 10+ 第三方 OAuth 平台。
- **M2-11 SSO 单点登录**：统一用户中心，支持 SSO 服务端与客户端模式，登录后按规则自动升级角色，支持跨域重定向白名单。
- **M2-12 MFA 多因素认证**：基于 TOTP 算法的二步验证，支持绑定/解绑 MFA 设备。
- **M2-13 外部认证集成**：对接外部 LDAP/OAuth 认证接口，本地验证失败时自动调用外部接口，通过后自动创建/更新本地用户。

### 3.3 M3 权限管理

- **M3-1 用户管理**：系统用户的增删改查与角色分配，支持查看用户的第三方链接、令牌、操作日志。
- **M3-2 角色管理**：角色的增删改查与菜单权限分配，支持按菜单分配 Action 级权限（查看/新增/编辑/删除/导出）。
- **M3-3 菜单管理**：无限级菜单树维护，每个菜单项可绑定 URL、图标、权限位，菜单树按用户权限动态生成。
- **M3-4 多租户**：租户间数据隔离，租户管理员可管理本租户用户。
- **M3-5 数据权限**：通过 `DataPermissionAttribute` 声明行级数据过滤规则，不同角色/用户看到不同数据行。
- **M3-6 委托代理**：用户间权限委托，支持设置委托有效期。
- **M3-7 访问规则**：基于 IP 白名单/黑名单的访问控制，支持按 Area/Controller/Action 配置。

### 3.4 M4 实体控制器与 CRUD

- **M4-1 标准 CRUD**：通用实体增删改查 API，`GET` 列表查询（分页/排序/搜索）、`GET /Detail` 查看详情、`POST` 新增、`PUT` 更新、`DELETE` 删除。
- **M4-2 ReadOnlyEntityController**：只读实体控制器基类，适用于日志、统计等只读场景，不暴露新增/编辑/删除接口。
- **M4-3 EntityTreeController**：树形结构实体的管理控制器，支持树形数据的列表展示与节点拖拽排序。
- **M4-4 列表页字段配置**：通过 `ListFields` 配置列表页显示的列、链接列（Url + 模板参数）、条件显示（DataVisible）。
- **M4-5 表单页字段配置**：通过 `FormFields` / `AddFormFields` / `EditFormFields` / `DetailFields` 配置字段只读/隐藏/必填/分组。
- **M4-6 字段元数据 API**：`GetFields?kind=List|Detail|AddForm|EditForm` 返回字段级配置（30+ 属性），驱动前端动态渲染。
- **M4-7 实体字段级验证**：基于 Model.xml 元数据的字段级校验，新增/编辑时自动校验必填项、字段长度等。
- **M4-8 高级搜索**：多条件组合查询，支持时间区间、关键字、枚举筛选、多选搜索，子类通过重写 `Search` 方法定制。
- **M4-9 数据导入导出**：Excel/Csv/Json/Xml 四种格式的数据导出，Excel/Csv 格式的数据导入。
- **M4-10 批量删除**：按 ID 列表批量删除，条件删除必须至少一个过滤条件。
- **M4-11 附件上传与绑定**：新增/编辑时可上传附件，附件自动绑定到业务记录。
- **M4-12 指令管理**：系统指令编码的定义与查询管理。

### 3.5 M5 系统管理

- **M5-1 系统配置**：运行时配置管理，通过 `ConfigController` 查看和修改 `CubeSetting`，配置持久化到数据库。
- **M5-2 字典参数**：键值对参数配置，支持全局和租户级，支持按分类筛选。
- **M5-3 审计日志**：用户操作日志的记录与查看，支持按用户/时间/操作类型筛选。
- **M5-4 数据库管理**：数据库表结构查看与 SELECT 查询执行。
- **M5-5 系统信息**：服务器运行状态信息展示（运行时、GC、进程、内存等）。
- **M5-6 IP 地理信息**：基于 NewLife.IP 库的 IP 地址归属地解析。
- **M5-7 定时作业**：基于 Cron 表达式的后台任务调度，支持作业的启用/禁用/立即执行。
- **M5-8 应用系统管理**：第三方应用的注册、密钥（AppSecret）管理与调用授权，支持应用级 OAuth 配置。
- **M5-9 应用日志**：第三方应用的 API 调用日志记录与查看，支持按应用/时间筛选。
- **M5-10 用户在线监控**：实时查看在线用户及其活动，支持强制下线。
- **M5-11 用户令牌管理**：用户访问令牌的查询与吊销。
- **M5-12 用户统计**：用户登录频次、活跃度等行为统计分析。
- **M5-13 地区管理**：行政区域数据的树形 CRUD 管理。
- **M5-14 部门管理**：组织架构的树形 CRUD 管理，支持用户归属部门。
- **M5-15 附件管理**：系统上传文件的统一管理，支持文件列表查看、搜索、下载与删除。
- **M5-16 文件存储**：分布式文件存储服务，支持本地文件系统和阿里云 OSS，提供统一管理界面。
- **M5-17 OAuth 配置管理**：第三方 OAuth 服务商的参数配置（AppKey/AppSecret），支持启用/禁用指定平台。
- **M5-18 OAuth 日志管理**：OAuth 认证调用的回调日志记录与查看。
- **M5-19 用户链接管理**：用户第三方账号绑定关系管理，支持查看与解绑。

### 3.6 M6 值集系统（LOV）

- **M6-1 值集定义**：LOV 值集元数据定义（编码、名称、类型），支持枚举型和列表型值集。
- **M6-2 值集枚举值**：枚举型值集的值项 CRUD 管理，支持排序和启用/禁用。
- **M6-3 值集列表配置**：列表型值集的查询与显示配置，配置数据来源和显示列。
- **M6-4 值集搜索字段**：列表型值集的搜索条件配置（搜索字段和搜索方式）。
- **M6-5 值集表格列**：列表型值集的显示列配置（列和顺序）。

### 3.7 M7 通知与消息

- **M7-1 邮件发送**：通过 SMTP 发送邮件通知，支持 SMTP 参数配置和发送测试邮件。
- **M7-2 邮件配置管理**：SMTP 服务器/端口/账号等邮件通道参数配置。
- **M7-3 短信发送**：通过短信通道（阿里云等）发送通知。
- **M7-4 短信配置管理**：短信服务商通道参数配置。
- **M7-5 站内通知**：系统内通知消息的记录管理，支持标记已读/未读。

### 3.8 M8 AI 集成

- **M8-1 AI 服务接口**：`IAIService` 大模型对接抽象层，支持配置 AI 提供方。
- **M8-2 AI 日志摘要**：定时任务自动分析审计日志，生成可读的 AI 摘要报告。
- **M8-3 AI 安全报告**：定时安全巡检与告警，自动扫描安全风险生成安全报告。

### 3.9 M9 前端皮肤与 UI

- **M9-1 MVC Razor 视图引擎**：第二代魔方的 Razor 服务端渲染，视图支持覆写（同名视图优先使用子项目文件）。
- **M9-2 WebAPI JSON API**：第三代魔方的统一 JSON API，`ApiResponse<T>` 响应结构，支持跨域。
- **M9-3 嵌入式静态文件服务**：前端资源编译到 wwwroot 后嵌入 DLL，物理文件优先于嵌入资源，支持覆写。
- **M9-4 SPA 回退路由**：非 API 请求自动返回前端入口页面，前端路由页面刷新不 404。
- **M9-5 MVC 主题皮肤系统**：多种 MVC 主题皮肤（AdminLTE/Metronic/Tabler/LayuiAdmin/ElementUI 等），引入 NuGet 包即可切换。
- **M9-6 自定义视图/列表页/表单页**：通过视图覆写机制自定义列表页、表单页、布局，子项目同路径同名 .cshtml 覆盖内置视图。
- **M9-7 Vue 前端皮肤**：Vue 3 + Element Plus 内置前端，引用 NuGet 包后开箱即用。
- **M9-8 React 前端皮肤**：React + Ant Design 内置前端，功能与 Vue 版对等。
- **M9-9 NaiveUI 前端皮肤**：Vue 3 + Naive UI，开箱即用。
- **M9-10 ArcoVue 前端皮肤**：Vue 3 + Arco Design Vue（字节跳动），开箱即用。
- **M9-11 Vuetify 前端皮肤**：Vue 3 + Vuetify 3 (Material Design)，开箱即用。
- **M9-12 TDesign 前端皮肤**：Vue 3 + TDesign（腾讯），开箱即用。
- **M9-13 MUI 前端皮肤**：React 19 + MUI 6 (Material Design)，开箱即用。
- **M9-14 Shadcn 前端皮肤**：React 19 + Radix UI + Tailwind CSS 4，开箱即用。
- **M9-15 Angular 前端皮肤**：Angular 19 + NG-ZORRO (Ant Design)，开箱即用。
- **M9-16 Svelte 前端皮肤**：SvelteKit 2 + Svelte 5 + Tailwind CSS 4，开箱即用。
- **M9-17 Blazor 前端皮肤**：基于 Blazor 的实验性前端，覆盖基础 CRUD 场景。
- **M9-18 ECharts 图表集成**：后端提供 `GetChartData` API，前端支持渲染柱状图/折线图/饼图等常见图表。
- **M9-19 Swagger API 文档**：按 Area 自动分组的 Swagger API 文档，引用 `NewLife.Cube.Swagger` 自动生成。

## 5. 不做什么

- **不绑定单一前端框架**：平台定位为后台快速开发 API 能力层，不要求用户使用特定前端框架
- **不要求 Node.js 环境**：前端由 CI 编译，NuGet 包含编译产物，用户无需安装 Node.js
- **不做低代码/无代码平台**：魔方是"代码生成 + 框架约束"的开发平台，不是拖拽式低代码平台
- **MVC 版（第二代）不新增主力功能**：进入弱化阶段，后续主要做存量兼容，主力演进 WebAPI 版（第三代）
- **不内置行业业务逻辑**：框架提供通用后台能力，ERP/CRM/OA 等业务逻辑由上层业务系统实现
