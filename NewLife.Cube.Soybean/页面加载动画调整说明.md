# 页面加载动画调整说明

> 适用范围：Huiyang.Skin.Soybean（Vue3 + Element Plus + UnoCSS）
> 涉及文件：`web/src/plugins/loading.ts`、`web/src/main.ts`、`web/src/locales/langs/zh-cn.ts`、`web/src/locales/langs/en-us.ts`

## 1. 动画来源与显示时机

首屏加载动画由 `setupLoading()` 生成一段静态 HTML 注入 `#app`，在 Vue 挂载前显示，Vue 挂载完成后被应用内容替换。

- 生成函数：`web/src/plugins/loading.ts` 的 `setupLoading()`
- 调用位置：`web/src/main.ts`，`setupLoading()`（在 `createApp` 之前调用）

注意：

- 该动画只出现在**首次进入应用、前端资源尚未加载完成**时；站内路由切换显示的是顶部 NProgress 进度条，列表请求数据显示的是 Element Plus 的 `v-loading` 遮罩，二者与本动画无关。
- 动画出现在 `/Cube/Site` 接口返回之前，因此**不能使用后端站点名称/Logo**，只能使用静态文案与内置 SVG。

## 2. 动画结构

`setupLoading()` 拼出的 DOM 结构（对应 `loading.ts` 第 40-51 行）：

```html
<div class="fixed-center flex-col bg-layout" style="--primary-color: ...; --logo-color-*: ...">
  <!-- Logo：128px 容器，内容为内置 SVG -->
  <div class="w-128px h-128px"> ...getLogoSvg()... </div>

  <!-- 旋转点：56px 容器，外层整体旋转，内部 4 个方块错峰闪烁 -->
  <div class="w-56px h-56px my-36px">
    <div class="relative h-full animate-spin">
      <div class="absolute w-16px h-16px bg-primary rounded-8px animate-pulse left-0 top-0"></div>
      <div class="absolute w-16px h-16px bg-primary rounded-8px animate-pulse left-0 bottom-0 animate-delay-500"></div>
      <div class="absolute w-16px h-16px bg-primary rounded-8px animate-pulse right-0 top-0 animate-delay-1000"></div>
      <div class="absolute w-16px h-16px bg-primary rounded-8px animate-pulse right-0 bottom-0 animate-delay-1500"></div>
    </div>
  </div>

  <!-- 标题文字：来自 i18n 的 system.title -->
  <h2 class="text-28px font-500 text-primary">系统名称</h2>
</div>
```

## 3. 可调整项

| 调整目标 | 位置（`web/src/plugins/loading.ts`） | 当前值 | 调整方式 |
|---|---|---|---|
| 整体背景 | 第 41 行 `bg-layout` | 主题布局背景 | 改为 `bg-white`、`bg-[#f5f7fa]` 或自定义类 |
| Logo 尺寸 | 第 42 行 | `w-128px h-128px` | 改宽高，如 `w-96px h-96px` |
| Logo 图形 | 第 43 行 `getLogoSvg()` | 内置 SVG（渐变取主题色） | 换成 `<img>` 或替换 SVG 内容，见 3.1 |
| 旋转点容器 | 第 45 行 | `w-56px h-56px my-36px` | 改边长与上下间距，如 `w-40px h-40px my-24px` |
| 单个点大小 | 第 36 行 | `w-16px h-16px rounded-8px` | 改尺寸与圆角，如 `w-12px h-12px rounded-6px` |
| 点的数量/位置 | 第 27-32 行 `loadingClasses` | 四角各一个 | 增删数组项即可，位置类如 `left-0 top-0`、`right-0 bottom-0`、`left-1/2 top-1/2` |
| 点闪烁节奏 | 第 29-31 行 | `animate-delay-500/1000/1500` | 改延迟值，或删除延迟让四点同步 |
| 整体旋转速度 | 第 46 行 `animate-spin` | UnoCSS 默认 1s | 改用任意值动画，如 `animate-[spin_1.5s_linear_infinite]` |
| 标题文字 | 第 50 行 `$t('system.title')` | 见 3.2 | 改语言文件，或在此处硬编码 |
| 标题字号/间距 | 第 50 行 | `text-28px font-500` | 改字号、字重，或加 `mt-*` |
| 暗色模式 | 第 23-25 行 | 读 `darkMode` 本地存储并加 `dark` 类 | 无需改动，跟随用户上次主题 |
| 主题色 | 第 9-21 行 | `themeColor`（本地存储），默认 `#646cff` | 与系统主题保持一致，一般不改 |

### 3.1 替换 Logo

**方案 A：保持内置 SVG，仅改尺寸**（改第 42 行容器类即可）。

**方案 B：换成图片 Logo**

将第 42-44 行替换为：

```html
  <img src="/Content/images/logo/NewLife.png" class="w-128px h-128px object-contain" alt="" />
```

说明：

- 图片必须是可在未登录状态访问的静态资源（同源或完整 URL）。
- 更换后不再使用主题色渐变（原 SVG 通过 `--logo-color-*` 跟随主题色）。

### 3.2 调整标题文字

标题取自 i18n 键 `system.title`：

- 简体中文：`web/src/locales/langs/zh-cn.ts` 第 3 行，当前为 `'Soybean 管理系统'`
- 英文：`web/src/locales/langs/en-us.ts` 第 3 行，当前为 `'SoybeanAdmin'`

修改语言文件会影响所有引用 `system.title` 的位置（如侧边栏菜单标题的兜底值）。若只想改加载动画的文字，直接把第 50 行改为固定文本：

```ts
  <h2 class="text-28px font-500 text-primary">Web管理平台</h2>
```

若不需要标题，删除第 50 行整行即可。

### 3.3 移除旋转点

删除第 45-49 行的整个容器块，只保留 Logo（和标题）。

## 4. 与站点名称/Logo 的关系

- 登录页、侧边栏显示的站点名来自后端 `/Cube/Site` 的 `name`，Logo 来自站点配置（`web/src/store/modules/site/index.ts`）。
- 加载动画发生在接口返回之前，只能用静态资源；若希望三处视觉一致，建议：
  1. 用 `system.title` 改成与站点名一致，或
  2. 把加载动画的 Logo 换成站点配置中同一张图片。

## 5. 生效步骤

1. 修改 `web/src/plugins/loading.ts` / 语言文件。
2. 重新构建皮肤前端：

   ```bash
   cd web
   npm run build
   ```

   产物输出到皮肤项目根目录 `wwwroot`（经 `Huiyang.Skin.Soybean.csproj` 内嵌进 DLL）。

3. 停止 6080 宿主进程后重新构建并启动（DLL 被占用会导致复制失败）：

   ```bash
   dotnet build E:\2026DevProject\Huiyang.HealthPlatform\Huiyang.HealthPlatform.csproj
   E:\2026DevProject\Bin\Web\Huiyang.HealthPlatform.exe
   ```

4. 浏览器访问 `http://localhost:6080/`，强制刷新（Ctrl+F5）并清缓存验证。

## 6. 验证提示

- 本地加载很快，动画可能一闪而过。可在浏览器 DevTools 的 Network 面板开启 Slow 3G 限速，或禁用缓存后刷新观察。
- 若页面已加载过旧前端，需硬刷新，确认入口脚本 hash 变化（`/assets/index-*.js`）。
- 修改仅涉及皮肤前端，不涉及后端业务代码。
