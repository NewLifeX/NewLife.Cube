NewLife.Cube إطار تطوير ويب سريع يجمع الصلاحيات وSSO وOAuth وCRUD للكيانات؛ ومع XCode يمكن بناء لوحة إدارة شبه دون كود.

## التثبيت

```bash
dotnet add package NewLife.Cube
```

## البدء السريع

```csharp
services.AddCube();
app.UseCube();

public class UserController : EntityController<User> { }
```

## الفريق
