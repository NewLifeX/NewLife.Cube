## 5. 完成标准（DoD）

- **后端功能**：主场景实现 + ≥1 边界 + ≥1 异常 + 参数校验 + 公开 API 注释
- **前端功能**：页面可加载（无 JS 错误）+ 列表/分页/搜索 + 增删改落库 + 删除确认 + 表单校验 + 空状态 + 错误状态 + 权限拦截 + E2E 覆盖
- 本皮肤为纯前端项目，所有功能按"前端功能"DoD 验收
- 配套后端修复：`NewLife.Cube` EntityController2 补 `ImportFile` 动作（Vue/React 通用），导出/导入权限对齐后端授权模型（Detail/Insert）
