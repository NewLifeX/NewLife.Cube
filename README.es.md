NewLife.Cube es un framework web de desarrollo rápido que integra permisos, SSO, OAuth y CRUD de entidades; con XCode, el panel de administración requiere casi ningún código.

## Instalación

```bash
dotnet add package NewLife.Cube
```

## Inicio rápido

```csharp
services.AddCube();
app.UseCube();

public class UserController : EntityController<User> { }
```

## Características

- Generación de código y API fuertemente tipadas con menos código repetitivo
- Autenticación, autorización, cifrado y protecciones de seguridad
- Integración perfecta con el ecosistema NewLife (XCode/Cube/Remoting)
