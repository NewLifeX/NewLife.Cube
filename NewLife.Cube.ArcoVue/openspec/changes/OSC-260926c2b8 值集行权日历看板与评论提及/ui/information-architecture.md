# 信息架构

三条线都落在现有页面，不新增路由。

## 值集

无新界面。下拉与名称翻译的结果变少时，空列表沿用现有 LOV 空态。

## 日历

月网格保持 7 列。事件条最多 3 条，第 4 条起为 `+N` 按钮，位于当日格子底部。弹出层锚在该按钮上，宽度不超过 280px，条目为事件标题，点击关闭弹层并打开右侧记录抽屉。

空白日：本月格子的日期数字和空白区域可点（有新增权时指针为手型）。非本月格子保持淡色且不可建记录。

## 看板

列头从左到右：列名、条数。整头可点。折叠后列宽 48px，列名省略，条数保留。展开宽度与今天相同。

## 讨论

输入框下方从左到右：已选用户标签、`people` 按钮、发送。弹出层在按钮上方，内有搜索框和最多 20 行用户。回复框使用同一顺序，状态与顶层评论分开。
