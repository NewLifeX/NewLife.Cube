## 验收标准

- [ ] AC-01：`NamedView.filter`/`group` 域随 ViewsJson 保存，重开视图自动应用；round-trip 不丢未知字段；非法/损坏方案安全归一。
- [ ] AC-02：筛选条件（等于/范围）并入后端请求，翻页/导出完整；filter 为空时请求与既有搜索一致；同名搜索参数按 filter 覆盖。
- [ ] AC-03：`等于` 对多选字段以逗号分隔提交；`范围` 输出 `_min/_max`（支持单侧）；未知/失效字段与空值不进入请求。
- [ ] AC-04：`且(AND)` 全部条件并入请求；`或(OR)` 多条件降级为前端二次过滤且有明确提示，单条件与 AND 等价。
- [ ] AC-05：多级分组（≤3 字段）表格内组头行展示 label+count，组头可折叠/展开；分组字段随视图保存；折叠状态仅会话内存。
- [ ] AC-06：分组为纯前端对已加载 `tableData` 分组，不并入请求；空数据/未知分组字段安全回退；不改变既有 CRUD 与权限。
- [ ] AC-07：筛选构建器与「保存到此视图」（FiltersJson 默认搜索）并存、互不覆盖。
- [ ] AC-08：Insight 搜索面板默认一行，溢出显示「展开更多 N」并可展开/收起；字段变化重置；未溢出不显示展开。
- [ ] AC-09：状态/枚举/单值 Lov 搜索字段下拉展示正确；LOV LIST 支持远程搜索（防抖/关键字）与已选标签移除；ENUM 与「更多」入口回归。
- [ ] AC-10：本 OSC 新增 Vitest 全过，api-core/web 构建无错误，事实性文档最小同步完成。
