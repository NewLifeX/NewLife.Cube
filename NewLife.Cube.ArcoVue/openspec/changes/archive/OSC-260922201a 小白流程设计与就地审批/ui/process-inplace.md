# 就地审批与设计语句

原则：当前界面能做完的事不再打开下一层。看进度和办审批分开。

## 设计器

画布铺满内容区。点节点从右侧打开属性抽屉（无遮罩，宽 400），关抽屉即取消选中。选人用六句话，不先展示 Id。连线「+」菜单五项短名各带图标，分支两项前有分隔条。审批 / 办理 / 知会仍用插入窗口，两种分支直接插入。条件分支只走一条；并行分支同时进入命中的分支，全部完成后汇合。卡片有单独标题栏，右侧垃圾桶删除；内容区只写接收人。审批人六种在属性抽屉里用下拉选择。

## 发起

一个抽屉。步骤预览和自选人在抽屉内部，没有子弹窗。

## 待办

| 点击 | 结果 |
| --- | --- |
| 同意 / 驳回 / 已办理 | 按钮旁气泡（窄屏为全宽对话框） |
| 更多 | 同一行下拉，需要选人时再用一个气泡 |
| 标题或「进度」 | 进度抽屉 |

## 记录已打开时

审批页签底部使用同一组按钮。进度面板（时间线 + 只读画布）嵌在页签里。不再从页签打开进度抽屉。
