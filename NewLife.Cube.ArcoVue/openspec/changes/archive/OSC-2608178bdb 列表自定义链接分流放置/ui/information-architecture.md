# OSC-2608178bdb UI 信息架构 — 列表自定义链接分流

对齐飞书多维表「行操作」与 Arco 中后台操作列；**不**把行级 Url 放入顶栏。

## 列表顶栏（不变）

```
[ + 添加记录 ]          [筛选] [分组] [搜索] [自动化?] [高级 ▾]
```

- 「高级」：导入 / 导出 / 批量删除 / 表单布局（OSC-0007）
- **禁止**：ListField.Url 自定义链接出现在顶栏或高级菜单

## 表格 / 树 — 数据区与操作列

```
| 勾选 | …数据列（含字段挂链接的可点单元格）… | 操作 |
                                      详情 编辑 删除 [链1] [链2] [自动…] [更多▾]
```

### 单元格链接（字段挂 Url）

- 列仍在表中，展示字段值；可点；站内 SPA，`_blank` 新窗。
- 文案优先单元格值，空则 DisplayName。

### 操作列自定义链接（合成 Url / dataAction）

- **直出**：最多 2 个（`OPS_LINK_INLINE_MAX`），链接色。
- **更多**：其余自定义链接进 Dropdown 菜单。
- **自动化按钮**：最多 3 个直出，位于自定义直出之后（OSC-260815fa86），本号不强制进更多。

### 点击语义

| 类型 | 反馈 |
| --- | --- |
| 导航 | 路由跳转或新窗 |
| dataAction | 请求中可 disabled 该项；结束 Message + 刷新 |

## 卡片 / 看板

```
┌ 卡片 ─────────────┐
│ 主字段（若 cell 链接则可点） │
│ …                 │
│ 详情 · 编辑 · 删除 · 链… · 更多 ▾ │
└───────────────────┘
```

与表格同一 `opsCustomLinks` 数据源与顺序规则。

## 日历 / 甘特

```
事件条 / 任务条：仅打开详情（不堆自定义链接）
        ↓
RecordDrawer：详情头或操作区列出同一组自定义链接（或「更多」）
```

## 分流一览（方案 E）

```
GetPage.list[]
    ├─ url + hasTypeName     → 数据列单元格链接
    ├─ url + !hasTypeName    → __ops 导航
    └─ dataAction 非空       → __ops AJAX（不进数据列）
```

## 对照

| 皮肤 | 本号 |
| --- | --- |
| Classic Bootstrap | 单元格为主 → 本号仅保留「字段挂链接」于单元格 |
| Metronic8 更多 | 全部 Url 进更多 → 本号改为分流，合成进 ops/更多 |
| 飞书行操作 | 操作列 + 溢出 → 对齐 |
