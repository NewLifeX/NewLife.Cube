# OSC-0003 UI 示意

信息架构（非视觉稿）。**壳**（顶栏/侧栏/主题）属 OSC-0004；本图仅 CRUD 内容区契约。

```
┌─ Layout（最小接线）─────────────────────────────┐
│ Sidebar(menus) │  Content                       │
│                │  ┌ DefaultList ──────────────┐ │
│                │  │ SearchBar                 │ │
│                │  │ Toolbar (CRUD/IO/Chart)   │ │
│                │  │ Table (flat | tree)       │ │
│                │  │ Pagination                │ │
│                │  └───────────┬───────────────┘ │
│                │              │ row click         │
│                │              row click →  RecordDrawer（右侧滑出）
│                │                                   ┌──────────────┐
│                │                                   │[表单][历史][评论*]│
│                │                                   │ FormContent… │
│                │                                   └──────────────┘
└────────────────────────────────────────────────┘
* 评论 Tab：OSC-0002 就绪后接线；此前空态/禁用
```

约束：

- 内容区组件不依赖主题 CSS 变量作为业务分支条件。
- 抽屉为记录级交互容器；不是换布局模式。
- **记录表单抽屉必须从右边弹出**（`placement="right"`），禁止左侧。
