# OSC-0004 UI 示意 — 壳与外观设置

本目录为信息架构说明，**非**像素稿实现。执行阶段按 Arco Design 与现有 ArcoVue 视觉落地。

## 壳信息架构

```
┌─────────────────────────────────────────────────────────┐
│  Logo / 产品名     [主题] [密度] [外观设置] [用户]        │  ← 顶栏快捷
├──────────┬──────────────────────────────────────────────┤
│          │  [页签1] [页签2] [×] …                        │  ← TagsView（可关）
│  菜单    ├──────────────────────────────────────────────┤
│  (side)  │                                              │
│          │              <router-view />                 │
│          │                                              │
└──────────┴──────────────────────────────────────────────┘
```

- **side**：左侧菜单 + 顶栏工具。
- **top**：顶栏水平菜单 + 内容区。
- **mix（最小可用）**：顶栏一级 + 侧栏二级。

## 外观设置页分组

1. **布局**：mode / siderWidth / showTabs / contentWidth  
2. **主题**：appearance / primaryColor / radius / fontScale  
3. **密度**：default | compact  
4. **操作**：保存（防抖自动） / 恢复默认  

路由：`/settings/appearance`（静态，无需菜单权限位）。

## 约束（视觉）

- 不改业务页（CRUD）信息架构。
- 抽屉仍从右侧滑出；壳变化不得把抽屉改成底部/左侧。
