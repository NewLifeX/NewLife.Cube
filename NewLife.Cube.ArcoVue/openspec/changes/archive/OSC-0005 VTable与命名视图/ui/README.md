# OSC-0005 UI — 飞书式表格视图（切片）

示意信息架构，非像素稿。参考 OSC-0003 `ui/` 多视图截图的工具条区域，本号只做 **table + 命名视图**。

## 列表页

```
┌─ 命名视图 [列表 ▾] [+]     [字段] [刷新] …权限按钮 ─────────────┐
│  搜索表单（既有）                                              │
├────────────────────────────────────────────────────────────────┤
│  VTable ListTable                                              │
│  [✓] | 冻结列… | 可见列…                        | 操作(固定)   │
│  …分页                                                         │
└────────────────────────────────────────────────────────────────┘
         行点击 → 右侧 RecordDrawer（不变）
```

## 命名视图下拉

- 列表项：名称；当前项勾选。
- 操作：新建（仅表格视图）、重命名、删除（最后一个不可删）、恢复默认。
- **不出现** 看板/树/甘特类型选择（0006）。

## 字段设置

- 显隐开关、拖拽排序、冻结（左）、可选重置列宽。
- 与飞书「隐藏字段」面板同级信息密度，Arco 抽屉或 Popover 即可。
