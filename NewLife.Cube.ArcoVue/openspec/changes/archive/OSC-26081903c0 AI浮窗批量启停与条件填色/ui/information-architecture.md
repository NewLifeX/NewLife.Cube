# OSC-26081903c0 UI 信息架构

框架：Arco Design Vue；表格 VisActor VTable。业务在 `useXxx.ts`。

## 壳 — AI 浮窗（登录后 RootLayout）

```
视口
  右下 [FAB robot-one]              ← 面板关闭
  右侧停靠 380×100vh                ← 打开后 FAB 隐藏；覆盖内容不挤布局
    header 48px
      [robot] AI 助手 [info]
      [more: 深度 / 清空] [最大化] [关闭]
    body
      空会话：👋 Hi，{displayName}
              副文案
              [推荐 | 提问 | 分析]
              可点建议行（分隔线）
      有会话：气泡 + 工具卡片
    footer
      多行输入    [send]
      Enter 发送 / Shift+Enter 换行
```

- 不进顶栏。不挡登录页。z-index 3000。
- 标题不是竞品品牌名。无历史、无附件、无「搭建」Tab。
- 窄屏面板 100vw。最大化 inset 20px。
- 流式中禁止第二路 SSE。

## 列表顶栏

```
[ + 添加 ]     [筛选 n] [分组 n] [填色 n] [搜索] [自动化?] [高级 ▾]
                                                          导入 / 导出
                                                          批量启用 / 批量禁用
                                                          批量删除 / 批量修改
                                                          表单布局
```

- 「填色」：**table / tree / card**；徽标=规则数，点徽标清空。看板/日历/甘特不显示按钮。
- 卡片弹层范围下拉只有「行侧边」「整行」，顺序为行侧边在前。
- 填色与筛选、分组弹层三选一互斥。
- 启停：无 Enable 或非 table 或无 Update 不渲染；0 选中 disabled。

## 填色弹层「设置填色条件」

```
设置填色条件
  ⠿  [色] [单元格▾] [字段▾] [等于▾] [请输入]  ×
  ⠿  [色] [行侧边▾] [字段▾] [小于▾] [请输入]  ×
  ⠿  [色] [整行▾]   [字段▾] [等于▾] [请输入]  ×
  + 添加条件
```

- 无页脚确定/取消；改即着色并写入当前命名视图。
- 无「智能全局配色」。
- 满 50 条时添加按钮禁用。
- 值控件按字段类别切换（文本/枚举/数字/日期/人员），为空/不为空不显示值。

## 表格着色

- 单元格/整行：按条件改数据单元格背景；**整行同时涂勾选列与操作列**。**整列**：只选字段，无条件铺满该列。不改文字色、不改徽标内部色。
- 色块打开 10 色明亮浅色预置板，点选即写入。
- **行侧边**：实体行最左侧 3px 竖条；分组头不画。
- 勾选列、操作列：不铺背景。

## 卡片着色

- **行侧边**：卡片左缘 3px 竖条。
- **整行**：色打在标题行 `.record-card-title`。
- 不涂卡片底、字段区、图片、操作按钮。
- 日历/甘特：按钮隐藏，不绘制。

## 明确不做的界面

- 顶栏 AI 入口（只要 FAB）。
- AI 会话历史、附件上传、「搭建」Tab、竞品品牌名。
- ViewConfigDrawer「条件格式」Tab。
- 填色弹层自然语言配色输入。
- 选中行第二条工具条。
- 渐变 / 色阶 / 图标 / 数据条 / 智能全局配色。
