# 列表热路径 — 可见行为

不新增页面、按钮或工具栏控件。日历导航、筛选构建器、页签条的 DOM 顺序不变。

## 表格高度（fit）

- 行少时表格变矮，底部跟着内容，不撑满一屏空白。
- 行多时表格停在当前视口可用高度内，在表内滚动。分页器仍在表格下方。
- `default` / `fill` 的填满方式不变。

## 日历数据

- 工具栏「今天 / ‹ / › / 标题」和日/周/月分段不变。
- 切换日期后列表按该窗口重新请求，底部仍是最多 1000 条的提示。
- 筛选构建器里看不到自动附上的起止条件。用户保存的筛选不含这两条。

## 页签

- 页签条仍列出打开过的页面。
- 超过 8 个已缓存页面时，最久没看的那个再点开会重新加载，页签本身还在。
