# OSC-260813397e UI 信息架构

## 登录（飞书风）

```
┌─────────────────────┬──────────────────────┐
│ 背景 loginBackground │ 登录 Tabs             │
│ Logo + 系统名        │ 表单 + 验证码          │
│ loginTip            │ [登录]                 │
│ copyright           │ 忘记密码 · 注册         │
│                     │ —— 第三方登录 ——        │
│                     │ [OAuth 图标…]          │
└─────────────────────┴──────────────────────┘
```

> 终验（T8）：登录页**不再**提供「租户 Code」；多租户在登录后于用户菜单分组切换。

MFA：右栏替换为「请输入验证器验证码」+ 备用码说明，无左栏变化。

## 账号安全

```
MFA 卡片：状态 / 开启或关闭
第三方：每行 提供商 | 已绑昵称 | 绑定/解绑
```

## 壳

用户头像弹出菜单（EnableTenant 且有可选项时）：
- 分组「租户 · {当前名}」→ 平铺可切换租户（含「平台」若有）
- 账号安全 / 外观设置 / 退出登录（各带图标）
