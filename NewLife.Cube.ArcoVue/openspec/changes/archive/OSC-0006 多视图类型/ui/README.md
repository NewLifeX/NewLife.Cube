# OSC-0006 UI — 多视图工作台

> 对齐飞书多维表格视图栏；列表区替换为类型化舞台。线框仅示意，视觉 token 沿用 ArcoVue 现网。

## 1. 工具条（Tab + 菜单 + 新建）

```
┌──────────────────────────────────────────────────────────────────┐
│ [表格] [看板] [日历] [···]  [+]                                    │
│  ▲活跃   Tab   Tab   当前视图菜单  新建视图                        │
├──────────────────────────────────────────────────────────────────┤
│ 搜索表单 …                                              [查询]    │
├──────────────────────────────────────────────────────────────────┤
│ ViewStage（table | tree | card | kanban | calendar | gantt）      │
└──────────────────────────────────────────────────────────────────┘
```

**`···` 菜单：** 重命名 · 自定义配置 · 复制 · 删除（最后一视图禁用删除或删后重建默认表）。

**`+` 菜单：** 表格 / 树状 / 卡片 / 看板 / 日历 / 甘特；门禁不满足项 **disabled + Tooltip 原因**。

## 2. 卡片单元（卡片视图 & 看板列内）

```
┌─────────────────────────────┐
│ 标题字段值                   │
│ ┌─────────────────────────┐ │
│ │      图片（可选）         │ │
│ └─────────────────────────┘ │
│ 标签A    值A    标签B  值B   │
│ 标签C    值C    …           │
│                             │
│ [详情] [编辑] [删除]   ← 左下；无权限则隐藏对应按钮 │
└─────────────────────────────┘
```

- 字段来自活跃视图 `columns`（visible），排除 title/image/(看板 groupField)。
- 操作与表格操作列权限一致：`canViewDetail` / `canEdit` / `canDelete`。

## 3. 看板

```
┌────── 待处理 ──────┬────── 进行中 ──────┬────── 已完成 ──────┬─ 未分组 ─┐
│ ┌卡片┐ ┌卡片┐      │ ┌卡片┐            │ ┌卡片┐            │ ┌卡片┐   │
│ └────┘ └────┘      │ └────┘            │ └────┘            │ └────┘   │
│ …                  │                   │                   │          │
└────────────────────┴───────────────────┴───────────────────┴──────────┘
         ← 横向滚动 →                    列内纵向滚动
```

- 列键 = `mapping.groupField`；选项序优先，无值进「未分组」。
- **只读**：不提供拖拽改列写回。

## 4. 日历（月）

```
┌ Sun Mon Tue Wed Thu Fri Sat ┐
│  1   2   3  [■■标题]  5  …  │
│  8  [色条事件] 10  …        │
└─────────────────────────────┘
```

- 区间 `[start, end||start]`；色 = colorField→badge，否则主题色。
- 点击事件 → 详情抽屉。

## 5. 甘特

```
┌ 任务名 │████████░░░░  start→end ┐
│ 任务B  │  ░░██████░░            │
└────────────────────────────────┘
```

- VisActor Gantt（或等价）；点击行/条 → 详情；不拖拽写回。

## 6. 配置抽屉「列表区」摘要

| kind | 控件 |
|------|------|
| table/tree | 分页器、允许详情、允许删除、展开 |
| card | 卡片标题、卡片图片 |
| kanban | **分组依据**、卡片标题、卡片图片 |
| calendar | 开始*、结束、标题、颜色 |
| gantt | 开始*、结束*、标题、颜色 |

顶栏与背景色：各类型共用（既有「顶栏区」）。
