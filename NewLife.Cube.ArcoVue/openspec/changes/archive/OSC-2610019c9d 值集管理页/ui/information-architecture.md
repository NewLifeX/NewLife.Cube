# 值集管理页

## 页面

路径 `/Admin/Lov`。上方工具栏：左侧「+ 添加值集」（对齐普通实体列表「添加记录」的位置与主按钮样式），右侧关键字、搜索、刷新。中间表格表面与表头样式对齐实体列表（`list-panel` + fill-2 表头）。定义抽屉宽度与记录抽屉相同；配置抽屉用宽抽屉（`RECORD_DRAWER_WIDE`），LIST 为「列表配置 / 搜索字段 / 表格列」三 Tab。

## 顺序

工具栏：左侧「+ 添加值集」；右侧从左到右为关键字输入、搜索、刷新。行操作从左到右：配置、编辑、删除。无权限的按钮不占位。

## 空态

无手工定义：表格空「暂无自定义值集」。配置类型不可写：抽屉内「该类型不能在此配置」。

## 断点

宽度小于 768 时表格横向滚动，抽屉仍为右侧全宽（沿用 `recordDrawerWidth` 的窄屏行为）。不单独做手机值集页。
