# 数据库管理子页

## 卡片

每个连接一张卡片。描述项不变（类型、版本、备份数）。底部按钮从左到右：数据库备份、备份并压缩、下载架构、更多；「更多」菜单含实体、压缩。（2026-10-03 修订：表、差异出口移除）

## 抽屉

实体列表与数据字典共用一个右侧抽屉，标题随视图变化（实体 · {连接} / 数据字典 · {实体中文名}）。实体列表列：显示名（描述首句，点击进入数据字典）/ 表名 / 行数（右对齐）/ 备注（描述余下部分，末列）；数据字典列：显示名 / 字段名 / 类型 / 长度（右对齐）/ 精度（右对齐）/ 主键 / 允许空 / 备注，工具栏含「返回实体列表」与「{type} · 共 N 个字段」。各列单行省略、溢出悬停 Tooltip（仅溢出时提示）；两表均允许横向滚动；表头不折行。压缩不打开抽屉，只用确认框。

## 空态

实体数组为空：抽屉内「无数据」；数据字典字段为空：「无字段」。

## 不做

不提供 SQL 输入框，不提供还原备份按钮。
