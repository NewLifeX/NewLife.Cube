# OSC-261004d7f4 — 实体地图散点视图

## 1. 目标愿景

把「地区管理」的一次性地图页沉淀为**通用视图类型**：任何带坐标字段的实体都能创建「地图视图」，在高德 / 百度 / 腾讯底图上铺满内容区展示对象散点；悬停出现透明玻璃卡片、点击进入详情；卡片内容与分类图标/颜色由视图配置抽屉（基础配置/字段配置 → 悬停内容；自定义配置 → 分类样式）定义。

- 目标 1：坐标字段自动识别（经度/纬度分列、合并坐标字段两种形态）；命中且系统已配置地图服务商才开放「地图」创建入口，否则不允许创建地图。
- 目标 2：地图视图全出血铺满内容区——无底部卡片、无分页器、无常规工具栏；保留视图 Tabs（切换视图 / 自定义配置 / 全屏）。
- 目标 3：悬浮玻璃质感工具栏为横条、置于地图右上角，含 缩小 / 放大 / 底图切换（标准↔卫星）/ 查询（含关键字搜索）/ 填色 五键（按钮或组合框；底图切换与关键字为验收反馈增补，2026-10-05 修订）；查询与填色复用现有弹层与规则。
- 目标 4：散点悬停显示玻璃卡片（字段与顺序来自「字段配置」），点击打开对象详情抽屉。
- 目标 5：自定义配置支持分类字段与「值 → 图标 / 颜色」规则；填色规则命中时覆盖分类颜色。
- 目标 6：地图服务商由服务端系统配置统一决定（同一时间仅配置一家：高德 / 百度 / 腾讯），经 `GetMapConfig` 只读下发；未配置时不允许创建地图视图，不做引导。

## 2. 为何做

三处参考互不通用：

- **CubeNC（MVC）** `Areas/Cube/Views/Area/Map.cshtml` + `AreaController.Map()`：ECharts + 百度底图（bmap 扩展）散点，整页独立（`PageSetting.EnableNavbar=false`、`Layout=null`），百度 AK 硬编码在视图里，数值为 `Rand.Next(10,300)` 演示随机数——只能看不能用。
- **WebAPI 版残留端点** `GET /api/Cube/Area/Map`（`ca567059` 地区管理地图模式引入）：省级（`ParentID=0`）+ 有经纬度城市 JSON，`Detail` 权限 + `FindAllWithCache` 一次加载。数据接口已就绪，但**前端未通用化**，且只服务地区一个实体。
- **React 皮肤历史实现**（`ca567059`，随后皮肤独立出库 `04df338a`，本仓前端已移除）：`AreaPage` 列表|地图双模式 + `AreaMap.tsx` ECharts 中国地图（本地 `china.json` 离线 GeoJSON，无外网依赖）三类散点（省份/城市/直辖市涟漪）+ 纯函数单测 + E2E——模式值得继承，但未沉淀为通用能力。
- **ArcoVue 现状**：无任何地图能力；但多视图体系（`ViewKind` 六种 / mapping / ViewConfigDrawer / 填色 / 查询组合框 / 记录详情抽屉 / `?id=` 自动开详情）完备，是「通用地图视图」的天然落点。

## 3. 已锁定范围

| # | 决策 |
| --- | --- |
| 1 | 地图作为第七种视图类型 `ViewKind='map'` 进入既有命名视图体系；映射存 `viewsJson.mapping`，不新增表/字段。 |
| 2 | 坐标识别仅覆盖两种形态：经度/纬度分列、合并坐标字段；GeoHash 反解、逆地理编码不做。 |
| 3 | 底图服务商由系统配置统一决定，同一时间仅一家（高德 \| 百度 \| 腾讯）；视图不逐视图选择服务商。 |
| 4 | 点位渲染走自有适配层 + 官方 JS SDK 动态加载；**不引入 npm 地图库/ECharts 依赖**。 |
| 5 | 数据复用实体列表查询（`GetPage`）分批渐进：首批 1000 条同步取回并按视口优先绘制，其余分页异步续拉（总上限 100 万，后端可支撑），拖动视口时增量绘制新进入对象；**点聚合暂缓**（2026-10-05 验收降级：三端适配层未实现，抽屉开关禁用，后续变更补做）；不新增实体数据接口。 |
| 6 | 工具栏仅 放大/缩小/查询/填色 四键；添加记录、导入导出、分组、排序、分享、高级菜单在地图视图不渲染。 |
| 7 | 悬停卡片内容 = 视图「字段配置」可见列（顺序、自定义标题与列表同语义）；卡片标题取 `mapping.titleField`。 |
| 8 | 分类规则上限 50 条；分类值键与看板分桶同源归一（dataSource 数字键优先）。 |
| 9 | 系统地图配置（服务商 + 密钥 + SDK 地址）进 `CubeSetting`（单服务商三字段），经 `GET /Cube/GetMapConfig`（对齐 `GetAiConfig`）只读下发；SDK 地址可覆盖以便内网自托管。 |
| 10 | 缺省坐标系 GCJ-02；可选 WGS-84 / BD-09，渲染前按目标底图自动换算。 |

## 4. 做什么

1. 视图类型扩展：`ViewKind` 增加 `'map'`，补齐 label / 默认名 / `parseViewKind` / 创建门禁 / seed / normalize / pageSize 全链；图标注册表与相关 spec 6→7。
2. 坐标检测纯函数 `mapCoord.ts`（分列/合并、字段名与显示名双通道、数值类型校验）；门禁理由「缺少坐标字段（经度/纬度或合并坐标字段）」。
3. `MapMapping` 类型与宽容归一化（坐标来源、坐标系、标题、分类、`DefaultLocation` 默认位置、`DefaultIcon` 默认样式、聚合、总上限）。
4. 地图适配层：高德/百度/腾讯适配器（含视口事件与增量增删点位）+ 动态脚本加载器（Key/URL 可配）+ 可注入 stub（离线/CI/E2E）；坐标系换算纯函数（WGS-84↔GCJ-02↔BD-09）。
5. `MapView.vue`：全出血地图、点位渲染（分类图标/颜色、填色覆盖）与视口渐进绘制（首批 1000 → 视口优先 → 异步续拉 → 拖动增量）、悬停玻璃卡片、点击详情、空态与无坐标点统计；未配置服务商时为普通空态，不做引导。
6. `DefaultList` 接入：地图视图隐藏常规工具栏/分页器/底部提示条，渲染右上角悬浮横条玻璃工具栏（五键，含底图切换），复用现有查询弹层与填色弹层。
7. 配置抽屉扩展：基础配置「地图」小节；字段配置在地图视图语义为「悬停卡片字段」；自定义配置新增「地图区」（分类字段 + 图标/颜色规则 + 默认样式）。
8. 后端：`CubeSetting` 单服务商三配置项（`MapProvider`/`MapKey`/`MapScriptUrl`）+ `GET /Cube/GetMapConfig`；api-core 封装与会话缓存接入。
9. 测试：纯函数 spec、门禁 spec、E2E（stub 离线可跑）+ 真实 SDK 手工冒烟。

## 5. 不做什么

- 不做轨迹/热力/区域填充（GeoJSON choropleth）、3D 等高级图层（卫星底图切换已于验收反馈轮增补交付，见 tasks I7）。
- ~~不做地图上的新增/编辑（添加记录仍走列表视图）。~~ 二轮迭代（2026-10-05，应使用反馈修订）：工具栏新增「+」**轻量添加记录**弹层（仅必填项 + 位置信息，支持**地图点击拾取**坐标）；地图上的**完整**编辑/新建仍走列表视图与详情抽屉。
- 不改 `/api/Cube/Area/Map`（保留兼容其它皮肤）；地区页仍可单独使用该接口。
- 不做 GeoHash 反解、逆地理编码、地址搜索。
- 不复刻 CubeNC 演示页的随机数值气泡。
- 不引入 npm 地图库/地图组件包，不加 ECharts 依赖。
- 不为 embed 分享/匿名短令牌新增地图专属能力（与列表同权）。
- 不为「未配置地图服务商」提供引导页/引导卡片（创建入口直接不可用）。
- 不引入高德、百度、腾讯以外的其它底图服务商（后续如需另立）。

## 7. 验收标准（AC）

- AC1 地区实体（含 `Longitude`/`Latitude`）创建菜单出现「地图视图」且可用；无可识别坐标字段、或系统未配置地图服务商的实体该项不可用（单测 + 截图）。
- AC2 地图视图铺满内容区：无底部卡片/分页器/常规工具栏；视图 Tabs 保留（DOM 断言 + 截图）。
- AC3 悬浮横条玻璃工具栏位于地图右上角，含 缩小/放大/底图切换/查询（含关键字搜索）/填色；缩放与底图切换生效（含边界与未就绪禁用）；查询与填色弹层可开且复用（E2E/实机）。
- AC4 悬停散点出现玻璃卡片，字段/顺序/自定义标题与「字段配置」一致；点击散点打开详情抽屉（E2E；stub 断言 + 真实 SDK 截图）。
- AC5 自定义配置选择分类字段并配置 值→图标/颜色 后，点位样式随规则变化；填色规则命中时颜色覆盖分类色（E2E 记录适配层入参）。
- AC6 系统未配置地图服务商时：创建菜单「地图视图」不可用；已存在的地图视图显示普通空态、不出现配置引导。配置服务商（三选一）后创建可用且加载正常（E2E + 手工各一）。
- AC7 门禁：新增 Vitest 全过、相关既有 spec 过、`vue-tsc -b` 0 错误、后端构建 0 错误。
- AC8 数据渐进：首批 1000 条先取回并按视口优先绘制；其余分页异步续拉（地区实体按缩放分层加载 L1–L4）；拖动视口后已加载未绘制的对象增量出现（stub 断言 `window.__mapStubMarkers` 数量增长；绘制统计经右下角定位按钮悬浮显示）（E2E/实机）。
