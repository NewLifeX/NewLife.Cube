# OSC-260824fc7c UI 信息架构

## 个人用户中心 `/account`

```
顶栏用户菜单
  个人信息     →  /account?tab=profile   或 SSO /Admin/User/Info
  账号安全     →  /account?tab=security
  外观设置     →  抽屉（本号不改）
  退出

/account
┌──────────────────────────────────────────┐
│ 资料 | 密码 | 安全 | 绑定                 │
├──────────────────────────────────────────┤
│ 资料：昵称 / 性别 / 邮箱 / 手机           │
│       只读：登录名、角色名                │
│ 密码：原密码 / 新密码 / 确认              │
│ 安全：MFA（397e 原页）                    │
│ 绑定：OAuth（397e 原页）                  │
└──────────────────────────────────────────┘
```

SSO 开且地址合法：资料/密码 Tab 不展示本地表单，只留「前往用户中心」主按钮。

## 角色授权（DefaultList 右抽屉）

```
角色列表（无 Permission 列）     右抽屉编辑
┌──────────────┐              ┌─────────────────────┐
│ 名称 系统 …  │              │ 名称 启用 系统 租户   │
│              │              │ 排序 备注             │
│              │              │ [全选][取消][展开][收起]
│              │              │ 菜单树（勾选权限叶）   │
└──────────────┘              └─────────────────────┘
```

目录节点无权限叶；叶子菜单下挂「查看/添加/修改/删除」或目录自定义位。系统角色：无列表删除；名称与系统开关锁定。

## 菜单 / 用户（仍 DefaultList）

- 菜单：Permission 只读 + 一句「EntityAuthorize 生成」。
- 用户：非系统角色且列表仅自己时，工具栏下警告条；角色分配仍用现有多选。
