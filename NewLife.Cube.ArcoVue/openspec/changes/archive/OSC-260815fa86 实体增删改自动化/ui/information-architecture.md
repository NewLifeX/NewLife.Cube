# OSC-260815fa86 UI 信息架构

入口只挂在 **实体列表**（`DefaultList`），不进对象主页/工作台。壳顶栏另有 **站内通知**（与实体入口独立）。

## 列表顶栏

```
[ + 添加记录 ]          [筛选] [分组] [搜索] [自动化] [高级 ▾]
                         ↑ entity 且 canUpdate 才显示「自动化」
```

「自动化」：text 按钮 + `lightning` 图标。点击打开右侧抽屉（中心约 880px，编辑约 1100px；<768px 全宽）。

## 壳顶栏（全局）

```
… [租户] [站内通知 remind + 徽标] [外观] [账号]
```

站内通知抽屉：标题「站内通知」；时间轴消息；工具栏「全部已读」；**无底部取消/确定**；点遮罩关闭。

## 自动化中心（列表态，飞书风卡片）

```
标题：自动化中心
[创建自定义流程] 卡片（首位，虚线） | [已有流程卡片…]（同屏，无「推荐/管理」双页签）
```

流程卡片：触发图标 → 动作图标；标题「触发 → …」；描述=名称·启用态；底栏开关/删除。点击卡片进入编辑。

## 编辑器（抽屉内，飞书双栏）

```
顶栏：← 返回 | 自动化流程
Tabs：编辑 | 运行日志（仅已保存流程）

编辑：
  名称
  ┌ 当以下情况发生时：     ┐  →  ┌ 就执行以下操作：        ┐
  │ 第 1 步                │     │ 第 2 步                 │
  │ 触发下拉               │     │ 动作卡片 Timeline       │
  │ 字段条件区（见下）     │     │ + 添加动作（8 项）      │
  └────────────────────────┘     └─────────────────────────┘
底栏：自然语言摘要 | 仅保存 | 保存并启用
运行日志：该规则的系统 Log（Action=Automation）
```

### 第 1 步 · 字段条件（飞书式卡片）

```
[同时满足以下条件]  [并且|或者]     [全选] [取消选择]
┌ 浅灰卡片 ─────────────────────┐
│ ☑ 🏷 字段名                    │
│ ───────────────────────────── │  ← 分隔线
│ 满足  [运算符 4/12] [值 8/12]  │
└───────────────────────────────┘
+ 添加同时满足的条件
```

- fieldChange 触发：标题改为「关注以下任一字段的变更」，嵌套标签「变更为」，不显示并且/或者。
- 每个字段独立小卡片；未勾选仅一行名称。

### 第 2 步 · 动作卡片头栏

```
[动作类型名]                    [⋯ 菜单] [∧ 收起]
                                ├ ⬆ 上移
                                ├ ⬇ 下移
                                └ 🗑 删除
```

- `⋯` 使用 IconPark `more`（横向省略号）；菜单项带适配图标。
- 收起/展开箭头在最右侧，字号/图标放大。
- 「添加动作」**不含**「运行自动化」（执行器仍支持旧图）。

### 发送通知 · 接收对象

```
渠道：[站内信 ▾]
接收对象：
  [用户|角色|部门]   ← 与「并且/或者」同款 button radio
  [多选下拉：搜索并选择…]  ← Recipients API + 实体 GetList 回退
标题 / 正文
```

## 行操作

```
详情 | 编辑 | 删除 | {按钮自动化1} | {按钮2} | {按钮3}
```

最多 3 个自动化按钮；非 button 无行按钮。

## 记录详情抽屉 Tab

```
[字段] [历史] [讨论]
```

**不**在实体添加/编辑/详情中放自动化运行日志（已迁入流程编辑器「运行日志」Tab）。历史筛选项仍可含 Action=`Automation`。

## 不做的界面

- FlowGram 画布、节点拖拽、分支线。
- 全局跨实体「自动化中心」独立菜单。
- 飞书消息触发配置项。
- 动作菜单「运行自动化」添加入口（旧图可编辑展示，不新增）。
