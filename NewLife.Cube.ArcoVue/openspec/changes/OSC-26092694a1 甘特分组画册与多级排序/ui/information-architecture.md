# 信息架构

不新增视图种类，不新增路由。

## 甘特配置

自定义配置抽屉的甘特区，在起止日期字段之下增加「分组字段」。第一项「不分组」。选择后立即写入 mapping 并刷新甘特。分组父节点在时间轴左侧表格中缩进显示子记录；父行没有详情按钮。

## 画册

卡片布局单选顺序：标准、偏大、整行、画册。画册卡片从上到下为图（160px）、标题、至多两个字段。无图时图区为填充色占位，高度仍是 160。

## 排序

表格与树视图工具栏，分组按钮旁增加「排序」。弹出层标题「排序」，每行：字段、升序或降序、删除。底部「添加排序」（已有 3 行时禁用）和「应用」。表头单击不打开此弹层，只替换为单列排序。
