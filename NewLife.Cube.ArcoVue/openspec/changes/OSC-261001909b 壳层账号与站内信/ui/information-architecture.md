# 壳层账号与站内信

## 菜单搜索

搜索框在 side、top、mix 的菜单列表之上，占菜单栏宽度。占位「搜索菜单」。结果面板贴在输入框下方，每行一个菜单名。超过 8 条不出现第 9 行，也不显示「更多」。

## 激活

独立页，无侧栏。有 token 时只显示结果与「返回登录」。无 token 时表单顺序：渠道、账号、验证码、发送验证码、提交。

## 注销

位于账号安全页签最底部，与 TOTP 区块分开。按钮文案「注销账号」。确认框标题「注销账号」，输入框标签「输入用户名以确认」。

## 站内信

点击一行：先标已读（样式变为已读），能解析 target 时关闭抽屉并进入实体详情。不能解析时抽屉保持打开，仅已读状态变化。

## 租户

「成员」在行操作或链接列中，文案固定「成员」。不新增「租户成员」整页向导。

## 明确没有的界面

菜单节点上没有上移、下移。地区列表没有地图按钮。没有语言切换。
