# 多租户新实体接入

共享库 + `TenantId` 字段隔离。缺一可能导致列表串租户或租户用户改隔离键。

## 清单（6 条）

1. **表字段** `TenantId`（Int32）。
2. **实体实现** `XCode.Membership.ITenantScope`（不要只加字段不加接口）。
3. **控制器**继承 `EntityController<T>`，列表走 `SearchData` / `FindAll(exp, p)`（基类 `CreateWhere` 会按 `TenantContext` 加过滤）。
4. **菜单** `[Menu(..., Mode = MenuModes.Admin | MenuModes.Tenant)]`，使租户管理员可见。
5. **非控制器写入**加 `TenantInterceptor`（或等价盖章），避免后台任务漏写 `TenantId`。
6. **自定义 Search** 调用 `ApplyTenant<T>()` 或依赖 `p.State` / 基类条件；平台 `TenantId=0` 不加过滤。

## 表单字段

开启多租户且当前 `TenantContext.CurrentId > 0` 时，基类 `OnGetFields` 会从 Add/Edit/Detail 移除 `TenantId`/`TenantName`，租户用户不可改隔离键。平台管理员可见。

## 请求上下文（SPA）

ArcoVue 在请求头注入 `X-Tenant: {code}`（`stores/tenant.ts` + `api/index.ts`）。登录后顶栏可切换；切换走 `POST /Auth/SwitchTenant`。

## CubeDemo 样例

`CubeDemo` 中 `Class` / `Student` 已实现租户相关接口，可作为学校业务实体参考，不强制改名。

## 本号不做

Expired 定时任务、MaxUsers 拦截、按 Domain 自动选租户。
