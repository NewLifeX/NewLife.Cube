# 字段组件规范

> 权威来源：OSC-26082097c1。本文件为 ArcoVue 字段控件的持久契约；后续表单/弹层/实现 OSC 以本文为准。  
> 本号为**纯文档**：不改运行时代码。实现另立 OSC（见 §10）。

## 1. 背景与目标

让 ArcoVue 用**一套 FieldKind 注册表**驱动所有表单与弹层（飞书多维表格/应用表单范式：**一类型、多表面**），消灭 `ControlType` / `SearchControlType` / `ListControlType` / `FilterFieldKind` 四套互不派生的推断。

| 目标 | 说明 |
| --- | --- |
| 目录可追溯 | 后端 `TypeName`/`ItemType` ↔ 统一 `FieldKind` ↔ 四表面行为 |
| 表面契约冻结 | `mode` + `density` + 值协议；消费方清单穷尽 |
| 缺口进目录 | 启发式专用件、只读公式/查找、TimeSpan 友好时长、详情 `labelIcon` |
| 实现切片 | 注册表 → FieldWidget 替换副本 → 目录 B 专用件（另立 OSC） |

**权威**：GetPage 下发的 `FieldMeta`。禁止前端发明列、改 `ReadOnly`、新增 GetPage `projections`。

**正交边界**：

| OSC | 职责 |
| --- | --- |
| OSC-0018 | 页面自定义分层（布局/视图等） |
| **本号** | **L0 字段控件契约** |
| OSC-260819e483 | 不新增 projections；公式/查找用扩展属性与 Map |

框架：表单壳用 **Arco Design Vue**；列表单元格文案语义约束 VisActor VTable（本规范不改列引擎）。

## 2. 解析模型

```
GetPage DataField → FieldMeta → resolveFieldKind → FieldKindSpec
  mode: edit | display | search | filter
  density: default | compact
```

### 2.1 FieldKindSpec 槽位

| 字段 | 含义 |
| --- | --- |
| `kind` | 稳定英文 id |
| `title` | 中文名 |
| `labelIcon` | 详情标签前 IconPark kebab 名（§8）。**禁止**命名为 `icon`（与 kind=`icon` 冲突） |
| `edit` / `display` / `search` / `filterOps` | 四表面 |
| `fullWidth` / density 降级 | 见 §3 / §7 |
| `serialize` | 提交归一（formula/lookup 剔除；duration 按存储单位） |

### 2.2 解析顺序（实现号必须单测锁定）

```
resolveFieldKind(field, ctx?):   # ctx.typePath 用于 ParentID 自树
  it = lower(itemType)
  if it in {password, secret} → password
  if it == icon → icon
  if it in {percent, percentage} → percent
  if it == gmk → bytes
  if it == code → code
  if it in {lovtable} → lovTable
  if it in {lovtablemulti} → lovTableMulti
  if it in {formula, compute, computed} → formula
  if it == lookup → lookup
  # 时长必须先于数值：Int32 + ItemType=TimeSpan（OnlineTime）不是普通数字
  if typeName == TimeSpan or it starts with timespan → duration
  # itemType=time / Time:* 是时刻，不得在已命中 duration 后再抢
  if typeName == Guid → readonly
  if Boolean / 布尔 dataSource → boolean
  # 名称启发式（先于 dataSource/lov 下拉）
  if matchTree(field, ctx) → inferIds(field) ? treeMulti : tree
  if matchPersonId(field) → inferIds(field) ? personMulti : person
  if matchRole(field) → inferIds(field) ? roleMulti : role
  if matchClientIp(field) → ip
  if matchLookupDisplay(field) → lookup
  # 可写外键保持 tree/person/lov；display 仍可 BatchLabel
  if dataSource nonempty → select / selectMulti
  if itemType 表 → …
  if lovCode → lov / lovMulti
  DateTime / 数值 / Enum / 枚举类 / String
```

`inferIds(name)`：`/ids$/i` 为多选。仅对白名单词干生效（§5）。`multiple===true` 或 `itemType=multipleSelect` 覆盖为多选。

- string：`eq neq contains notContains isNull notNull`

## 5. 名称启发式

### 5.1 树状级联 — 部门 / 地区 / 菜单

将现 `CascaderField`（写死 `/Cube/Area`）泛化为 `TreeCascader`：

| treeKind | 命中 | API |
| --- | --- | --- |
| `area` | itemType∈{area,area4,cascader}；`AreaId`/`AreaIds`/`AreaID` | `GET /Cube/Area?parentid=` |
| `department` | `DepartmentId`/`DepartmentID`/`DepartmentIds`；显示名含「部门」且为外键；lovCode 指向部门 | `GET /Cube/DepartmentSearch?parentid=` 或 `/Admin/Department` |
| `menu` | `MenuId`/`MenuID`/`MenuIds`；显示名含「菜单」且为外键 | `GET /Admin/Menu` |

自身父级：`typePath` 为上述实体且字段为 `ParentID`/`ParentId` → 同种 `tree`（排除自己）。

**禁止**：这些字段再走普通 `a-select` / 无树 Lov。

### 5.2 人员选择器

**ID 字段才绑** PersonSelect（存 `User.ID`）：

- 审计 ID：`CreateUserID` / `UpdateUserID` 等
- 显示名为创建者/更新者等 **且** 字段名以 `Id`/`ID` 结尾
- 通用：`UserId` / `UserIds` / `CreatorId` / `UpdaterId`

**字符串孪生列** `CreateUser` / `UpdateUser`（姓名快照）：**不是**人员选择器。

**审计**：`isAuditField` 仍从新增/编辑表单去掉创建/更新用户、**IP、时间**。人员控件用于搜索/筛选/填色/非审计 `UserId`。

### 5.3 Id vs Ids

白名单词干：`User` `Person` `Role` `Department` `Area` `Menu` 及 CreateUser/UpdateUser 的 ID 变体。

- `RoleId` → role；`RoleIds` → roleMulti
- `UserId` → person；`UserIds` → personMulti
- `DepartmentId` → tree(department)；`AreaId` → tree(area)；`MenuId` → tree(menu)
- 主键恰好 `Id`/`ID` → 不误判为人员/角色

### 5.4 终端 IP

命中（任一）：字段名 `CreateIP`/`UpdateIP`（整词）；或显示名恰好「创建地址」/「更新地址」。

**不是**地图。任意含 `IP` 的字段（如 `Vip`）**不是** ip。

审计：CreateIP/UpdateIP 不进新增/编辑表单；列表/详情/搜索/筛选走 `ip`。

## 6. 只读公式与查找引用

### 6.1 `formula`

| 项 | 约定 |
| --- | --- |
| 值 | **仅**实体 JSON 已有属性；禁止浏览器求值、禁止用户脚本 |
| 命中 | **仅** `itemType` ∈ {formula, compute, computed}。无「只读且不在表单」模糊启发式 |
| 提交 | `serializeSubmitModel` **剔除** |
| 搜索 | GetPage search 含该字段时按 typeName；否则无值控件 |

`ListField.GetValue` 委托不可下发 SPA；计算值须成为普通 JSON 属性。

### 6.2 `lookup`

| 项 | 约定 |
| --- | --- |
| 显示 | `MapField` + `lovCode` + `POST /Admin/Lov/BatchLabel` |
| 命中 | `itemType=lookup`；或 mapField 展示列（如 RoleName），**不是**可写外键 |
| 可写外键 | `RoleId`/`DepartmentId`/`UserId` 仍为 role/tree/person/lov；编辑改 ID |
| 禁止 | 写回关联表、双向同步、前端 join、未下发关联列（不新增 projections） |

## 7. 时长友好格式

对齐 MVC `ViewHelper.FormatValue` 的**单位解析**；默认展示为用户友好中文，不是 `TimeSpan.ToString()` 或时钟 `HH:mm:ss`。

| 项 | 约定 |
| --- | --- |
| 命中 | `typeName===TimeSpan` **或** `itemType` 以 `TimeSpan` 开头（含 `TimeSpan:format`） |
| 典型 | `User.OnlineTime`：`Int32` + `ItemType=TimeSpan`，单位秒 |
| 默认单位 | **秒** |
| 单位覆盖 | `FieldMeta.description`：毫秒/`ms` → 秒 → 分 → 小时（先「毫秒」再「秒」） |
| 自定义 | `TimeSpan:{format}` 时 display **优先**该格式 |
| 提交 | 同一存储单位数字；禁止提交友好中文或时钟串 |
| 不命中 | 仅描述含「秒」而无 TimeSpan 标记的 Int32（如「默认7200秒」）保持 `number` |

**`formatDuration`**：省略零档（`90`→`1分钟 30秒`；`90000`→`1天 1小时`）；全零 `0秒`；空 `-`；负号前缀。列表/详情/卡片/看板/搜索/筛选回显共用。

**DurationInput**：分段天/时/分/秒；compact 可纵向或「自动单位+数字」；search 不是 timePicker；filterOps 同 number，比较在归一化秒上。

## 9. 表面契约

### 9.1 mode

| mode | 用途 |
| --- | --- |
| `edit` | FieldWidget → 专用件 |
| `display` | formatFieldValue / fieldBadge / 缩略图；详情同 |
| `search` | 高级搜索等值（OSC-0016）；无 `_min/_max` |
| `filter` | 筛选/填色/自动化；`isNull`/`notNull` 无值控件 |

### 9.2 density

| density | 使用处 | 约束 |
| --- | --- | --- |
| `default` | FormContent、DefaultObject、编辑抽屉 | 完整预览 |
| `compact` | 筛选/填色/批量/单元格 | `size=small`；json/html/markdown→textarea；image 不预览；填色值区约 132px |

### 9.3 只读 / 空值 / 审计

| 条件 | 行为 |
| --- | --- |
| readOnly / display / formula / lookup | 不写入；edit 可 disabled |
| null / `''` | display `-` |
| isAuditField | 新增/编辑不展示（含 CreateIP/UpdateIP、时间、创建更新用户） |
| password | display 不展示明文；search/filter 无值控件 |
| duration | `formatDuration`；DurationInput；禁止 timePicker |

### 9.4 FieldWidget（实现号）

```
props: field, modelValue?, mode: edit|search|filter, density?, disabled?, typePath?, op?
emits: update:modelValue, search?
```

display 用纯函数，不强制进 Widget。

## 10. 值协议

继续 OSC-0008：

- 数值字符串 → number（超安全整数保留字符串）
- Boolean `'true'/'1'` → true
- 枚举类纯数字字符串 → number
- 多选：位掩码或逗号分隔
- **formula / lookup 不进提交体**
- **duration** 按存储单位写数字

保留函数名：`normalizeSubmitValue`、`serializeSubmitModel`、`isAuditField`、`isTenantField`。
