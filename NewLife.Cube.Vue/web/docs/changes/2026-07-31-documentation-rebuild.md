# 2026-07-31：前端文档重建

## 目的

将 `docs/` 从混合的设计草案、通用模板、实现计划和一次性重构报告，重建为按读者问题分层的长期文档系统。

## 结构

- `architecture/`：当前系统边界与运行链。
- `standards/`：UI、代码、API、测试和文档维护约束。
- `guides/`：开始开发、新增页面/API/组件、覆盖页面、主题和测试。
- `reference/`：配置、环境变量、路由约定、默认页面引擎和组件目录。
- `decisions/`：稳定的关键取舍。
- `operations/`：构建、发布、排障。

## 清理策略

已过期的 Boreal 视觉方案、旧 token 体系、未落地设计提案、通用 Vue 模板和一次性 API 重构展示不再保留在当前文档中。它们不具有后续开发指导价值，直接删除并由 Git 历史追溯。

本变更不归档旧文档，避免 `archive/` 变成新开发会误读的第二权威来源。
