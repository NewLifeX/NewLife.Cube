# 交互模式

> 不需要"设计"交互，只需要"选择"预设模式。每类场景只有一种标准表现。

## 加载

| 场景                     | 表现                | 组件                                                   | 为什么                                                |
| ------------------------ | ------------------- | ------------------------------------------------------ | ----------------------------------------------------- |
| 首次进入页面，无历史数据 | 骨架屏              | `el-skeleton`                                          | 保持布局稳定（避免 CLS 布局偏移），传达"结构即将出现" |
| 已有数据，刷新/翻页/筛选 | 局部 loading 遮罩   | `v-loading` 指令（`CbTable` 已内置 `dataSet.loading`） | 传达"结构已在，数据在更新"，不应重新闪烁骨架          |
| 按钮触发的异步操作       | 按钮自身 loading 态 | `el-button :loading="submitting"`                      | 反馈聚焦在触发点，不需要遮罩整页                      |

## 空态（区分"从未有数据"与"筛选无结果"）

| 场景                          | 文案方向                  | 引导操作             |
| ----------------------------- | ------------------------- | -------------------- |
| 初始空态（列表从未有数据）    | "还没有 XX，创建第一个吧" | 主按钮：新建         |
| 筛选空态（筛选/搜索后无结果） | "没有符合条件的结果"      | 次按钮：清除筛选条件 |

统一使用 `el-empty`，通过 `description` 和 `#default` 插槽区分上述两种文案与按钮，不要两种场景共用同一段文案。

## 错误

| 层级                        | 表现                                  | 组件                                      |
| --------------------------- | ------------------------------------- | ----------------------------------------- |
| 页面级（整页数据加载失败）  | 页面内嵌错误提示，带重试按钮          | `el-alert`                                |
| 操作级（某次提交/删除失败） | 短暂提示                              | `ElMessage.error`                         |
| 全局崩溃（组件渲染异常）    | 兜底页面                              | `PageNotFound.vue` / 全局 `errorCaptured` |
| 断网                        | 顶部/角落持久提示，网络恢复后自动消失 | `ElNotification`                          |

## 确认与反馈

| 场景                                           | 组件                                                  | 依据                 |
| ---------------------------------------------- | ----------------------------------------------------- | -------------------- |
| 轻量确认（单条删除、单一后果）                 | `el-popconfirm`                                       | 不打断上下文         |
| 重量确认（批量删除、不可逆操作、需要二次输入） | `el-dialog` + 显式二次输入或 `ElMessageBox.confirm`   | 提高误操作门槛       |
| 操作成功/失败                                  | `ElMessage.success` / `ElMessage.error`               | 短暂、非阻塞         |
| 需要用户主动处理的通知（如后台任务完成）       | `ElNotification`                                      | 更持久，可带跳转按钮 |
| 复制到剪贴板                                   | `navigator.clipboard` + `ElMessage.success('已复制')` | 统一反馈文案         |

## 表单规则

| 维度         | 规则                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------- |
| label 位置   | 统一放在输入框上方（`label-position="top"`），仅密集表单可用左对齐，两种不混用于同一个表单内 |
| 必填标记     | 统一用 Element Plus 默认的红色星号（`required` 属性），不额外加文字"（必填）"                |
| 校验时机     | 失焦校验（`blur`）+ 提交时全量校验；不做逐字符实时校验（会造成"边输边报错"的噪音体验）       |
| 错误信息位置 | `el-form-item` 默认位置（字段下方），不使用弹窗/顶部汇总代替字段级错误                       |

## 导航与数据密度

| 维度            | 规则                                                                                                       |
| --------------- | ---------------------------------------------------------------------------------------------------------- |
| 面包屑          | 仅列表页/详情页二级以上路径出现；仪表盘/全屏工作区不需要                                                   |
| tab vs 侧栏子壳 | 分类 ≤ 4 个且不需要独立 URL → `el-tabs`；分类 > 4 个或需要独立分享/前进后退 → 侧栏子壳（见 page-types.md） |
| 表格默认密度    | `size="default"`；数据密集型页面（如日志、监控）可用 `size="small"`，两种不在同一页面混用                  |

## 错误边界与降级

| 场景                                       | 处理                                                                              |
| ------------------------------------------ | --------------------------------------------------------------------------------- |
| 组件渲染异常                               | Vue `errorCaptured`/`onErrorCaptured` 兜底，避免整页白屏                          |
| 局部区块加载失败（如某张图表数据请求失败） | 该区块单独显示 `el-alert` 重试提示，不影响页面其他区块                            |
| 断网                                       | 全局拦截器捕获网络错误，`ElNotification` 提示"网络已断开"，恢复后自动提示"已恢复" |

## 检查口诀

写完交互后自问：这个场景是"从未有数据"还是"筛选无结果"？是"轻量确认"还是"重量确认"？是"页面级错误"还是"操作级错误"？答案不确定时查本文件，不要凭直觉现场发明一种新表现。
